# ML 전처리 테스트 v4

## 목표

v4에서는 `test/CJ/test_docs/3. 참고 자료` 폴더의 자료를 이용해 시대 라벨 정확도를 보강했다.

이번 개선의 핵심은 문제지와 해설지만으로는 흔들리는 키워드의 시대 판단을 참고 자료 기반 키워드 보정표로 보완하는 것이다.

## 사용한 참고 자료

참고 자료 경로:

```text
test/CJ/test_docs/3. 참고 자료
```

확인한 파일:

```text
1. 한국사 인물사 (근현대사).pdf
2. 한국사 지역사 (북한, 충청, 전라, 경상, 기타).pdf
3. 5대 궁궐 및 문화재.pdf
4. 한능검 기출 역사서.pdf
[꿈꾸는라이언] 한능검 요약노트 (78회 업데이트).pdf
```

이 자료들은 문항별 정답 라벨로 직접 쓰기보다, 핵심 키워드가 어느 시대에 속하는지 확인하는 기준 자료로 사용한다.

## 발견한 문제

48~50회 결과를 확인한 결과, 일부 문항에서 시대가 잘못 분류되어 있었다.

대표 예시는 다음과 같다.

```text
48회 19번: 정도전 -> 고려로 분류
49회 17번: 훈련도감 -> 조선 전기로 분류
49회 37번: 과거제 폐지 -> 고려로 분류
49회 46번: 조선 건국 동맹 -> 조선 전기로 분류
50회 11번: 훈련도감 -> 조선 전기로 분류
50회 32번: 을미의병 -> 일제 강점기로 분류
```

이 문제는 `era_reference.json`의 일반 키워드 매칭만으로는 맥락을 충분히 구분하지 못해서 발생했다.

## 변경 사항

### 1. 참고 자료 경로 상수 추가

`ML_feature_data.py`에 참고 자료 경로를 추가했다.

```python
REFERENCE_DOCS_DIR = DOCS_DIR / "3. 참고 자료"
```

### 2. 키워드 시대 보정표 추가

새 파일을 추가했다.

```text
test/CJ/test_ml/ml_keyword_era_overrides.json
```

이 파일은 참고 자료를 바탕으로 확실하게 시대가 갈리는 키워드를 관리한다.

예시:

```json
{
  "조선 전기": ["정도전", "경국대전", "세종", "훈민정음"],
  "조선 후기": ["훈련도감", "대동법", "균역법", "탕평책"],
  "개항기": ["과거제 폐지", "을미의병", "갑오개혁"],
  "일제 강점기": ["조선 건국 동맹", "안창호", "신흥무관학교"]
}
```

### 3. 시대 판단 우선순위 변경

`reference_era_for_core()`가 이제 아래 순서로 시대를 판단한다.

```text
1. ml_keyword_era_overrides.json
2. MANUAL_ERA_OVERRIDES
3. era_reference.json
```

즉, 참고 자료 기반으로 확정한 키워드가 가장 먼저 적용된다.

### 4. 프롬프트 참고자료 보강

`load_reference()`에 참고 자료 기반 확정 키워드와 참고 PDF 목록이 포함되도록 변경했다.

문제지 Vision과 해설지 Vision이 분류할 때 참고할 수 있는 기준이 늘어났다.

### 5. CSV BOM 대응

PowerShell `Export-Csv`로 저장된 CSV는 BOM이 붙을 수 있어 Python에서 `round_no` 컬럼을 못 읽는 문제가 있었다.

CSV 읽기 부분을 `utf-8-sig`로 변경했다.

```python
open(csv_path, encoding="utf-8-sig")
```
