- 기존 피처 파일은 수정하지 않았고, 분포 확인용 리포트입니다.
- 인밸런스 판단은 실제 학습에 들어가는 `train(47~70회)` 기준으로 봅니다.

## 6. 해석

- 세부 유형을 풀이 패턴으로 묶으면 train 기준 클래스 수가 12개에서 6개로 줄어듭니다.
- 최대/최소 비율은 기존 `question_subtype`의 137.20배에서 `solving_pattern`의 89.88배로 낮아집니다.
- 다만 `자료 기반 대상 추론`이 train 기준 719건으로 59.9%를 차지하므로, 여전히 쏠림은 큽니다.
- 즉 병합만으로 희소 라벨 문제는 줄어들지만, 자료 기반 유형이 넓다는 문제는 남습니다.
- 그래도 기존 `question_type`의 `역사 자료의 분석 및 해석` 60.8%와 비교하면 의미가 더 명확한 라벨이므로, 모델 타깃으로는 `question_type`보다 `solving_pattern`이 더 설명력이 좋습니다.

## 7. 권장

1. 1차 실험에서는 `era`, `topic`, `solving_pattern` 3개 모델을 사용합니다.
2. `solving_pattern` 학습 시 class weight와 Macro F1을 반드시 적용합니다.
3. `자료 기반 대상 추론`이 너무 넓게 남는지 샘플 검토 후, 필요하면 우선순위 기반 재라벨링을 추가합니다.
4. 기존 `question_type`과 `question_subtype`은 입력값이 아니라 보관/분석용 컬럼으로 유지합니다.
