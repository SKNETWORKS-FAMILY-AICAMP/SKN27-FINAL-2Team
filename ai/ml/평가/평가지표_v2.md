# 평가지표 v2

## 1. 실험 개요

- 실험명: TF-IDF baseline v1
- 모델: `TfidfVectorizer(char_wb 2~5gram) + LogisticRegression`
- 인밸런스 처리: train 기준 `class_weight` 적용
- 학습 데이터: `split_v1/train_features_v1.json`
- 예측 입력 데이터: `split_v1/predict_input_v1.json`
- 평가 정답 데이터: `split_v1/test_answer_v1.json`
- split: train 47~70회 1,200문항 / test 71~78회 400문항

## 2. 결과 파일 보관 위치

- `ai/ml/output/baseline_tfidf_v1/baseline_tfidf_results_v1.json`
- `ai/ml/output/baseline_tfidf_v1/baseline_tfidf_results_v1.md`
- `ai/ml/output/baseline_tfidf_v1/era_predictions_v1.csv`
- `ai/ml/output/baseline_tfidf_v1/topic_predictions_v1.csv`
- `ai/ml/output/baseline_tfidf_v1/question_type_predictions_v1.csv`

## 3. 핵심 지표

| target | Accuracy | Macro F1 | Weighted F1 | 1차 해석 |
|---|---:|---:|---:|---|
| era | 0.6850 | 0.6349 | 0.6670 | baseline으로는 가장 안정적 |
| topic | 0.4300 | 0.3260 | 0.3847 | 성능 낮음, 개선 필요 |
| question_type | 0.7925 | 0.3664 | 0.8461 | Accuracy는 높지만 Macro F1 낮음 |

## 4. target별 해석

### era

- Accuracy `0.6850`, Macro F1 `0.6349`로 세 target 중 가장 안정적이다.
- 시대 라벨은 지문 내 인물, 사건, 제도, 왕명 같은 키워드가 직접적으로 드러나기 때문에 TF-IDF baseline과 잘 맞는 편이다.
- 다만 남북국 시대, 초기 국가처럼 train/test 모두 상대적으로 적은 라벨은 여전히 낮게 나올 수 있다.

### topic

- Accuracy `0.4300`, Macro F1 `0.3260`으로 가장 낮다.
- 주제는 같은 지문 안에서도 정치/사건/인물/제도/문화가 겹치기 쉬워 단어 패턴만으로 구분하기 어렵다.
- 특히 소수 주제나 의미가 겹치는 주제는 class weight를 적용해도 충분히 분리되지 않았다.
- 다음 개선에서 가장 우선적으로 봐야 할 target이다.

### question_type

- Accuracy `0.7925`, Weighted F1 `0.8461`은 높지만 Macro F1 `0.3664`는 낮다.
- test 데이터에서 `역사 자료의 분석 및 해석` 비중이 매우 높기 때문에 Accuracy가 높게 보인다.
- Macro F1이 낮다는 것은 소수 문항 유형을 균형 있게 맞히지는 못했다는 뜻이다.
- 이 target은 Accuracy보다 Macro F1과 라벨별 F1을 중심으로 판단해야 한다.

## 5. 이번 실험에서 확인한 점

- `split_v1` 구조를 사용해 모델 입력 파일에서 test 정답 라벨을 제거했다.
- 모델은 `predict_input_v1`의 `text`만 보고 예측했고, 평가는 `test_answer_v1`과 비교했다.
- 따라서 test의 `era/topic/question_type` 정답을 보고 예측했다는 데이터 누수 의심은 줄어들었다.
- 예측 결과 CSV에 `true_label`, `pred_label`, `is_correct`를 저장해 행 단위 검토가 가능해졌다.

## 6. 다음 개선 방향

1. `topic` 성능 개선을 우선한다.
   - `input_text`와 `keywords`를 분리해서 feature 조합을 실험한다.
   - `topic` 라벨 기준이 겹치는 샘플을 검토한다.
   - 소수 topic 라벨의 예측 결과를 행 단위 CSV로 확인한다.
2. `question_type`은 Accuracy보다 Macro F1 중심으로 보고한다.
   - 다수 라벨 중심의 착시를 명시한다.
   - 소수 유형을 맞히지 못하면 모델 활용 범위를 제한한다.
3. 다음 실험 후보
   - TF-IDF 파라미터 변경: `ngram_range`, `min_df`, `max_features`
   - 단어 단위 TF-IDF와 char n-gram 비교
   - `input_text`만 사용 vs `input_text + keywords` 비교
   - KLUE/RoBERTa fine-tuning 준비

## 7. 현재 결론

- `era` 모델은 baseline 단계에서 활용 가능성이 있다.
- `topic` 모델은 현재 baseline으로는 부족하며, 가장 먼저 개선해야 한다.
- `question_type` 모델은 전체 정확도는 높지만 인밸런스 영향을 크게 받으므로 Macro F1 기준으로 조심스럽게 해석해야 한다.
- TF-IDF baseline은 딥러닝 모델 성능 비교를 위한 기준점으로 사용할 수 있다.
