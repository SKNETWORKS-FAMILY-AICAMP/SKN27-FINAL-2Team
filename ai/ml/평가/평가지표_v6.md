## 4. 해석

### era

- Accuracy는 TF-IDF보다 크게 올랐다.
- Macro F1은 거의 비슷하다.
- BERT가 다수 시대를 더 잘 맞히면서 전체 정확도는 좋아졌지만, 소수 시대까지 균형 있게 개선한 것은 아니다.
- `고조선`은 예측 수가 0으로 나타나 class weight 적용 필요성이 있다.

### topic

- BERT v1에서 가장 좋지 않은 결과가 나왔다.
- Accuracy와 Macro F1 모두 TF-IDF보다 낮다.
- 소수 topic 라벨인 경제, 군사, 사상·종교, 사회, 외교 계열을 거의 예측하지 못했다.
- class weight 미적용 상태에서는 다수 라벨 중심으로 학습된 것으로 보인다.
- 다음 실험에서 가장 먼저 class weight 효과를 확인해야 하는 target이다.

### question_type

- Accuracy는 TF-IDF보다 약간 낮고, Macro F1은 아주 조금 높다.
- `역사 자료의 분석 및 해석`, `연대기의 파악` 중심으로 예측이 몰려 있다.
- test에서 support가 거의 없는 라벨이 있어 Macro F1 해석에 주의가 필요하다.
- 소수 유형 개선에는 class weight 또는 라벨 재검토가 필요하다.

## 5. 이번 실험에서 확인한 점

- BERT가 항상 TF-IDF보다 좋은 것은 아니다.
- 데이터가 적고 라벨 불균형이 큰 경우, BERT도 다수 라벨 위주로 예측할 수 있다.
- 특히 topic은 class weight 없이 학습하면 소수 라벨을 거의 포기하는 양상이 나타났다.
- 따라서 “BERT 기본 모델” 다음 단계로 class weight 적용 실험을 진행할 근거가 생겼다.

## 6. 다음 개선 방향

1. KLUE/RoBERTa v2에서 class weight를 적용한다.
   - `CrossEntropyLoss(weight=class_weight_tensor)` 방식으로 적용한다.
   - 특히 topic Macro F1 개선 여부를 확인한다.
2. topic 오분류 CSV를 확인한다.
   - 다수 라벨로 쏠리는 문제를 확인한다.
   - 라벨 기준이 애매한 샘플이 있는지 검토한다.
3. question_type은 소수 라벨 support 문제를 별도로 기록한다.
   - test에 없는 라벨은 평가 지표 해석에서 제외하거나 별도로 설명한다.

## 7. 현재 결론

- BERT v1은 era Accuracy를 개선했지만, 전체적으로 TF-IDF baseline을 압도하지는 못했다.
- topic은 BERT v1에서 오히려 악화되었으므로 class weight 적용이 필요하다.
- 다음 실험은 `KLUE/RoBERTa + class weight`로 진행한다.
