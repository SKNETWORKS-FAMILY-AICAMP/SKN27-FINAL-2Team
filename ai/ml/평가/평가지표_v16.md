# 평가지표 v16 - KLUE/RoBERTa v5 Topic Merged 결과

## 1. 실험 개요

v5는 RunPod 환경에서 실행한 통합 주제 실험이다.

- Model: `klue/roberta-base`
- Target: `era`, `topic_train`
- Excluded target: `question_type`
- Topic merge: `정치/경제/사회/군사/외교 -> 정치`, `문화/사상·종교 -> 문화`
- Class weight: 적용
- Cross validation: 3-fold Stratified Cross Validation
- Max length: 512
- Max epochs: 8
- Early stopping patience: 2

## 2. 전체 요약

| target | cv accuracy | cv macro f1 | cv weighted f1 | final epochs | test accuracy | test precision | test recall | test macro f1 | test weighted f1 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| era | 0.7350 | 0.6843 | 0.7360 | 4 | 0.7950 | 0.7760 | 0.7784 | 0.7763 | 0.7956 |
| topic_train | 0.6067 | 0.5822 | 0.5985 | 3 | 0.4500 | 0.4420 | 0.5030 | 0.4558 | 0.4401 |

## 3. 시대 era 결과 해석

`era`는 현재까지 가장 안정적인 target이다.

- test accuracy: 0.7950
- test macro f1: 0.7763
- test weighted f1: 0.7956
- CV macro f1: 0.6843

CV보다 test 성능이 더 높게 나왔고, confusion matrix에서도 대부분의 시대가 대각선에 잘 모인다.
`초기 국가`는 support가 15개로 적고 f1-score가 0.5806이라 상대적으로 약하지만, 전체적으로 실사용 가능한 수준에 가깝다.

## 4. 통합 주제 topic_train 결과 해석

`topic_train`은 라벨을 5개로 줄였는데도 test 성능이 낮다.

- test accuracy: 0.4500
- test macro f1: 0.4558
- test weighted f1: 0.4401
- CV macro f1: 0.5822

CV에서는 macro f1이 0.58 정도였지만, 71~78회차 test에서는 0.46까지 떨어졌다.
따라서 단순히 라벨 개수가 많아서 생긴 문제라기보다, train 구간과 test 구간의 출제 표현 차이 또는 통합 라벨 자체의 의미 혼재가 영향을 준 것으로 보인다.

## 5. topic_train 클래스별 지표

| label | precision | recall | f1-score | support |
|---|---:|---:|---:|---:|
| 문화 | 0.5294 | 0.5094 | 0.5192 | 53 |
| 사건 | 0.5050 | 0.6623 | 0.5730 | 77 |
| 인물 | 0.4242 | 0.5316 | 0.4719 | 79 |
| 정치 | 0.4737 | 0.2761 | 0.3488 | 163 |
| 제도 | 0.2778 | 0.5357 | 0.3659 | 28 |

가장 큰 문제는 `정치` recall이다.
test에서 실제 `정치`가 163건으로 가장 많지만, 그중 45건만 정치로 맞췄다.
정치 문제 163건 중 상당수가 `사건`, `인물`, `제도`, `문화`로 흩어졌다.

## 6. Confusion Matrix 주요 패턴

`topic_train`에서 실제 `정치`의 예측 분포는 다음과 같다.

| actual 정치 -> predicted | 건수 |
|---|---:|
| 문화 | 18 |
| 사건 | 36 |
| 인물 | 39 |
| 정치 | 45 |
| 제도 | 25 |

정치 통합 라벨은 의미 범위가 너무 넓다.
정치 안에 경제, 사회, 군사, 외교까지 들어가면서 오히려 문항 텍스트만으로는 사건/인물/제도와 경계가 흐려진 것으로 보인다.

## 7. Loss 그래프 해석

`era`는 validation loss가 4 epoch 근처에서 가장 좋고 이후 큰 개선이 없다.
최종 학습 epoch가 4로 잡힌 것은 적절하다.

`topic_train`은 validation loss가 3 epoch 이후 다시 상승한다.
train loss는 계속 내려가지만 validation loss가 올라가므로 과적합이 시작된 것으로 볼 수 있다.
early stopping으로 final epoch가 3으로 잡힌 것은 정상적인 판단이다.

## 8. 결론

`era`는 현재 모델 구조로 계속 사용해도 된다.

`topic_train`은 통합했는데도 성능이 충분히 개선되지 않았다.
특히 `정치` recall이 낮아서 최신 출제 트렌드 분석에 그대로 사용하면 정치 비중을 과소평가할 위험이 있다.

현재 결론은 다음과 같다.

```text
era: 유지 가능
topic_train: 추가 개선 필요
question_type: 현재 예측 제외 유지
```

## 9. 다음 실험 제안

바로 더 큰 모델이나 복잡한 튜닝으로 가기 전에, `topic_train` 라벨 설계를 다시 확인하는 것이 우선이다.

추천 순서:

1. `정치`로 통합된 원본 라벨별 성능을 따로 확인한다.
2. 정치로 통합된 문제 중 사건/인물/제도로 예측된 문제 샘플을 직접 확인한다.
3. 지문 전체만 사용할지, 문제 질문/보기/키워드 조합을 분리해서 사용할지 검토한다.
4. 이후 learning rate, batch size, warmup, max length를 조정한다.

현재 v5 결과만 보면 `MAX_LENGTH=512`나 GPU 성능 문제가 핵심은 아니다.
핵심 병목은 `topic_train` 라벨의 의미 경계와 train/test 분포 차이로 보는 것이 더 타당하다.
