# 평가지표 v5

## 1. 변경 목적

TF-IDF baseline 평가를 완료했으므로, 다음 단계로 BERT 계열 모델을 사용한다.

이번 v5 실험은 성능 개선 과정을 단계적으로 기록하기 위한 기본 BERT 실험이다.

```text
v5: KLUE/RoBERTa 기본 모델, class weight 미적용
v6: KLUE/RoBERTa + class weight 적용 예정
```

## 2. 실험 설정

| 항목 | 값 |
|---|---|
| 모델 | `klue/roberta-base` |
| 평가 방식 | 시간순 평가 |
| 학습 데이터 | `split_v1/train_features_v1.json` |
| 예측 입력 | `split_v1/predict_input_v1.json` |
| 평가 정답 | `split_v1/test_answer_v1.json` |
| target | `era`, `topic`, `question_type` |
| class weight | 미적용 |
| max length | 256 |
| epoch | 3 |
| batch size | 8 |
| learning rate | 2e-5 |

## 6. 확인할 점

1. TF-IDF 시간순 baseline보다 성능이 좋아지는지 확인한다.
2. 특히 `topic` Macro F1이 개선되는지 본다.
3. `question_type`에서 소수 유형 성능이 개선되는지 확인한다.
4. class weight를 적용하지 않은 기본 성능을 먼저 기록한다.
