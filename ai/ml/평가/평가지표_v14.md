# Topic 통합 라벨 데이터 v1

## 1. 회의 결정

주제(`topic`)와 문제유형(`question_type`) 평가 결과를 검토한 결과, 다음 방향으로 정리했습니다.

- `question_type`은 라벨 쏠림이 커서 우선 학습 target에서 제외를 검토한다.
- `topic`은 소수 라벨을 기존 대표 라벨로 통합해 성능 변화를 확인한다.
- 새 라벨명은 만들지 않고, 기존 라벨명 안에서만 통합한다.

## 2. 통합 방식

원본 `topic`은 보존하고, 학습용 라벨 `topic_train`을 새로 만들었습니다.

| 원본 topic | 학습용 topic_train |
|---|---|
| 정치 | 정치 |
| 경제 | 정치 |
| 사회 | 정치 |
| 군사 | 정치 |
| 외교 | 정치 |
| 문화 | 문화 |
| 사상·종교 | 문화 |
| 인물 | 인물 |
| 사건 | 사건 |
| 제도 | 제도 |

## 3. 생성 파일

새 데이터는 기존 `split_v1`을 수정하지 않고 별도 폴더에 생성했습니다.

```text
ai/ml/output/split_topic_merged_v1/
```

주요 파일:

```text
train_features_topic_merged_v1.json
predict_input_topic_merged_v1.json
test_answer_topic_merged_v1.json
full_features_topic_merged_v1.json
topic_merge_report_v1.md
ml_han_topic_merged_class_weights_v1.json
ml_han_topic_merged_class_weights_v1.md
ml_han_topic_merged_weighted_train_v1.jsonl
ml_han_topic_merged_weighted_test_v1.jsonl
```

## 4. 검증 결과

| 파일 | 건수 | topic_train 상태 |
|---|---:|---|
| train_features_topic_merged_v1 | 1200 | 정답 라벨 포함 |
| predict_input_topic_merged_v1 | 400 | 전부 빈칸 |
| test_answer_topic_merged_v1 | 400 | 정답 라벨 포함 |

`predict_input_topic_merged_v1`의 `topic_train`은 모두 빈칸으로 확인했습니다.
따라서 예측 입력 데이터가 정답 topic_train을 보고 학습/예측하는 누수는 없습니다.

## 5. Train topic_train 분포

| topic_train | train 건수 | 비율 |
|---|---:|---:|
| 사건 | 340 | 28.3% |
| 인물 | 304 | 25.3% |
| 정치 | 272 | 22.7% |
| 문화 | 148 | 12.3% |
| 제도 | 136 | 11.3% |

기존 topic에서는 5% 미만 라벨이 있었지만, 통합 후 train 기준 모든 topic_train 라벨이 10% 이상으로 정리되었습니다.

## 6. Test topic_train 분포

| topic_train | test 건수 | 비율 |
|---|---:|---:|
| 정치 | 163 | 40.8% |
| 인물 | 79 | 19.8% |
| 사건 | 77 | 19.2% |
| 문화 | 53 | 13.2% |
| 제도 | 28 | 7.0% |

test에서도 모든 통합 라벨이 5% 이상 존재합니다.

## 7. 다음 실험 방향

다음 학습에서는 target을 아래처럼 가져가는 것이 적절합니다.

```text
era
topic_train
```

`question_type`은 이번 실험에서 제외합니다.

주의할 점:

- 예측 결과가 `정치`이면 원본 정치/경제/사회/군사/외교가 포함된 학습용 라벨이다.
- 예측 결과가 `문화`이면 원본 문화/사상·종교가 포함된 학습용 라벨이다.
- 원본 의미를 확인해야 할 때는 `topic` 컬럼을 함께 확인해야 한다.
