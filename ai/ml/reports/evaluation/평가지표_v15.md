# 평가지표 v15 - v5 실험 기준 정리

## 1. 버전 유지 원칙

v4까지의 실험은 그대로 유지한다.

- `klue_roberta_v4.ipynb`: 기존 v4 결과 확인용으로 보존
- v4 target: `era`, `topic`, `question_type`
- v4 데이터: `split_v1`
- v4 주요 설정: `MAX_LENGTH = 384`, `MAX_EPOCHS = 8`, `3-fold Stratified Cross Validation`, class weight 적용

v5부터 새 실험으로 분리한다.

- `klue_roberta_v5.ipynb`: 통합 주제 실험용
- v5 target: `era`, `topic_train`
- v5 제외 target: `question_type`
- v5 데이터: `split_topic_merged_v1`
- v5 주요 설정: `MAX_LENGTH = 512`, `MAX_EPOCHS = 8`, `3-fold Stratified Cross Validation`, class weight 적용

## 2. v5에서 변경한 이유

기존 `topic`은 일부 라벨의 비율이 낮아 예측 성능이 불안정했다.
회의 결과에 따라 새 라벨을 만들지 않고, 기존 라벨 의미 안에서 유사 범주를 통합해 학습 난도를 낮추는 방향으로 정리했다.

`question_type`은 데이터가 한쪽으로 크게 쏠려 있어 현재 단계에서는 예측 대상에서 제외한다.
문제 생성이나 학습 계획 생성에서 필요한 경우, 모델 예측값이 아니라 기존 전처리 라벨 또는 별도 규칙 기반 정보로 활용하는 방향이 더 적절하다.

## 3. 주제 통합 방식

원본 `topic`은 보존하고, 학습용 라벨 `topic_train`을 추가했다.

| 원본 topic | 학습용 topic_train |
|---|---|
| 정치 | 정치 |
| 경제 | 정치 |
| 사회 | 정치 |
| 군사 | 정치 |
| 외교 | 정치 |
| 문화 | 문화 |
| 사상·종교 | 문화 |
| 인물 | 인물 |
| 사건 | 사건 |
| 제도 | 제도 |

## 6. v5 결과 확인 항목

각 target마다 아래 항목을 확인한다.

```text
accuracy
macro precision
macro recall
macro f1
weighted f1
class별 precision / recall / f1-score / support
confusion matrix
cross validation fold별 accuracy / macro f1 / weighted f1
```

특히 `topic_train`은 기존 `topic`과 라벨 수가 다르므로 v4의 `topic` 결과와 단순 1:1 비교하면 안 된다.
비교할 때는 "원본 주제 10개 분류"에서 "통합 주제 5개 분류"로 문제 정의를 바꿨다는 점을 같이 적어야 한다.
