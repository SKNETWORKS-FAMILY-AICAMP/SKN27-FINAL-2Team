# KLUE/RoBERTa 평가 지표 종합

## 1. 평가 목적

한국사 기출문제 텍스트를 입력으로 받아 다음 3개 target을 예측하는 모델을 평가합니다.

- `era`: 시대
- `topic`: 주제
- `question_type`: 문항 유형

평가 데이터는 71~78회차입니다.
학습 데이터는 47~70회차입니다.

## 2. 평가 항목 정의

| 평가 항목 | 의미 | 이번 프로젝트에서 보는 이유 |
|---|---|---|
| Accuracy | 전체 문제 중 정답을 맞힌 비율 | 전체 성능 확인 |
| Precision | 해당 클래스로 예측한 것 중 실제로 맞은 비율 | 모델이 특정 클래스를 남발하는지 확인 |
| Recall | 실제 해당 클래스 중 모델이 맞힌 비율 | 소수 클래스가 무시되는지 확인 |
| F1-score | Precision과 Recall의 균형 | 클래스별 성능 균형 확인 |
| Macro F1 | 클래스별 F1을 단순 평균 | 데이터 불균형 상황에서 핵심 지표 |
| Weighted F1 | 클래스 support를 반영한 F1 평균 | 실제 분포 기준의 종합 성능 확인 |
| Confusion Matrix | 실제 클래스와 예측 클래스의 교차표 | 어떤 클래스끼리 헷갈리는지 확인 |

Confusion Matrix는 `0.xxxx` 형태의 단일 점수가 아닙니다.
따라서 별도 PNG와 행렬 표로 확인하며, 해석은 주요 오분류 패턴 중심으로 기록합니다.

## 3. 버전별 실험 개요

| 버전 | 변경/추가한 내용 | 변경 이유 |
|---|---|---|
| v1 | KLUE/RoBERTa 기본 학습 | BERT 계열 기본 성능 확인 |
| v2 | validation loss, early stopping, loss graph 추가 | 과적합 여부와 적정 epoch 확인 |
| v3 | class weight, Confusion Matrix 추가 | 클래스 불균형 대응 및 오분류 패턴 확인 |
| v4 | `MAX_LENGTH=384`, `MAX_EPOCHS=8`, `PATIENCE=2`, 3-fold StratifiedKFold 추가 | 긴 지문 반영, 충분한 학습 기회 제공, 평가 안정성 확보 |

## 4. v4 최종 평가 지표

### era

```text
accuracy: 0.7775
precision: 0.7638
recall: 0.7499
f1-score: 0.7514
macro f1: 0.7514
Weighted F1: 0.7801
Confusion Matrix: era_klue_roberta_v4_confusion_matrix.png
```

해석:

- v1~v4 중 가장 좋은 결과입니다.
- 대부분의 시대가 대각선 중심으로 예측됩니다.
- 남북국 시대, 초기 국가 등 일부 시대는 여전히 주변 시대와 혼동됩니다.

### topic

```text
accuracy: 0.4175
precision: 0.4463
recall: 0.3540
f1-score: 0.3510
macro f1: 0.3510
Weighted F1: 0.3963
Confusion Matrix: topic_klue_roberta_v4_confusion_matrix.png
```

해석:

- v1~v4 중 가장 좋은 Macro F1입니다.
- 경제, 군사, 사상·종교, 사회, 외교 등 소수 클래스가 v3보다 일부 살아났습니다.
- 정치, 인물, 사건 간 혼동은 여전히 큽니다.
- topic은 가장 어려운 target입니다.

### question_type

```text
accuracy: 0.7750
precision: 0.3630
recall: 0.4328
f1-score: 0.3718
macro f1: 0.3718
Weighted F1: 0.8380
Confusion Matrix: question_type_klue_roberta_v4_confusion_matrix.png
```

해석:

- v3에서 class weight 과보정으로 떨어졌던 성능이 회복되었습니다.
- Accuracy는 v1과 같고, Weighted F1도 v1과 거의 유사합니다.
- Macro F1은 v1보다 약간 낮습니다.
- test set에 support가 0인 문항 유형이 있어 Macro F1 해석에 주의가 필요합니다.

## 7. 성능 향상을 위해 바꾼 것

### validation loss + early stopping

추가 버전: v2

변경 이유:

- 고정 epoch만 사용하면 과적합 여부를 확인하기 어렵습니다.
- validation loss를 기준으로 best epoch를 찾기 위해 추가했습니다.

결과:

- v2에서는 실제 early stopping이 발생하지 않았습니다.
- validation 분리로 학습 데이터가 줄어 era/question_type은 하락했고 topic만 소폭 상승했습니다.

### class weight

추가 버전: v3

변경 이유:

- topic, question_type은 클래스 불균형이 큽니다.
- 다수 클래스만 맞추는 모델을 줄이기 위해 소수 클래스 loss를 더 크게 반영했습니다.

결과:

- era: Macro F1 상승
- topic: Macro F1 상승
- question_type: 과보정 발생, 성능 하락

### Confusion Matrix

추가 버전: v3

변경 이유:

- Accuracy와 F1만으로는 어떤 클래스를 헷갈리는지 알 수 없습니다.
- class weight 적용 후 예측 쏠림이 완화됐는지 확인하기 위해 추가했습니다.

결과:

- era는 대각선 중심으로 안정적입니다.
- topic은 정치/인물/사건 혼동이 큽니다.
- question_type은 `역사 자료의 분석 및 해석`과 `연대기의 파악` 간 분산이 주요 이슈입니다.

### max_length 증가

변경 버전: v4

변경 내용:

- `MAX_LENGTH=256` -> `MAX_LENGTH=384`

변경 이유:

- 한국사 사료형 문제는 지문이 길 수 있습니다.
- 256 토큰에서 잘리는 정보를 줄이기 위해 증가했습니다.

결과:

- era, topic, question_type 모두 v3보다 개선되었습니다.

### epoch 증가

변경 버전: v4

변경 내용:

- `MAX_EPOCHS=3` -> `MAX_EPOCHS=8`
- `PATIENCE=1` -> `PATIENCE=2`

변경 이유:

- v2/v3에서 best epoch가 대부분 마지막 epoch였습니다.
- 더 학습할 여지가 있다고 판단했습니다.
- epoch를 늘렸기 때문에 validation loss가 한 번 흔들렸다고 바로 멈추지 않도록 patience도 2로 늘렸습니다.

결과:

- fold별 best epoch 평균은 era 4.333, topic 3.667, question_type 5.667입니다.
- 기존 3 epoch보다 더 학습하는 것이 도움이 되었습니다.

### Stratified K-Fold

추가 버전: v4

변경 내용:

- `3-fold StratifiedKFold`

변경 이유:

- 단일 validation split은 결과가 특정 분할에 의존할 수 있습니다.
- 클래스 비율을 유지하면서 여러 fold로 평가해 안정성을 확인했습니다.

결과:

- v4는 모든 target에서 v3보다 개선되었습니다.
- 특히 topic Macro F1이 0.2677에서 0.3510으로 상승했습니다.

## 8. 최종 판단

현재 기준 최종 후보는 v4입니다.

| target | 최종 판단 |
|---|---|
| era | v4 채택 가능 |
| topic | v4가 가장 좋지만 추가 개선 여지 큼 |
| question_type | v4 사용 가능, 다만 v1과 유사 수준이므로 추가 튜닝 필요 |

## 9. 다음 실험 후보

v5를 진행한다면 한 번에 많이 바꾸기보다 v4를 기준으로 하나씩 비교합니다.

- `MAX_LENGTH=512`: 긴 지문이 더 많은지 확인
- class weight 완화: 특히 question_type 과보정 방지
- topic 전용 튜닝: topic은 여전히 가장 낮은 성능
- label 재검토: topic/문항 유형의 의미 중복 또는 불균형 확인
