# 평가지표 v1

## 1. 현재 평가 목적

- 과거 기출문제(47~70회)로 학습한 모델이 최신 기출문제(71~78회)에도 적용되는지 확인한다.
- 모델은 문제 텍스트를 입력받아 `시대(era)`, `주제(topic)`, `문항 유형(question_type)`을 각각 예측한다.
- 평가 결과는 최신 출제 경향 분석, 문제 추천, 문제 생성 방향 설정에 활용한다.

## 2. 사용 데이터

| 항목 | 내용 |
|---|---|
| 원본 통합 데이터 | `ai/ml/ML_han_v1.json` |
| 피처 데이터 | `ai/ml/output/ml_han_features_v1.json` |
| weighted train 데이터 | `ai/ml/output/ml_han_weighted_train_v1.jsonl` |
| weighted test 데이터 | `ai/ml/output/ml_han_weighted_test_v1.jsonl` |
| class weight 파일 | `ai/ml/output/ml_han_class_weights_v1.json` |

## 3. 학습/평가 분리

| split | 회차 | 문항 수 | 목적 |
|---|---:|---:|---|
| train | 47~70회 | 1,200 | 과거 기출 기반 모델 학습 |
| test | 71~78회 | 400 | 최신 기출 적용 가능성 검증 |

층화추출은 현재 메인 평가 방식으로 사용하지 않는다.  
이 프로젝트의 목적이 “과거 문제로 최신 문제를 설명할 수 있는가”에 가까우므로 시간 순서 기반 분리를 우선한다.

## 4. 모델 입력과 예측 라벨

### 입력

- `input_text`
- `keywords`

정답 라벨인 `era`, `topic`, `question_type`은 입력에 넣지 않는다.  
라벨을 입력에 넣으면 모델이 문제 내용을 학습하는 것이 아니라 정답 힌트를 보는 데이터 누수가 생길 수 있다.

### 예측 라벨

| 모델 | 입력 | 출력 |
|---|---|---|
| 모델 1 | `input_text + keywords` | `era` |
| 모델 2 | `input_text + keywords` | `topic` |
| 모델 3 | `input_text + keywords` | `question_type` |

`question_subtype`은 인밸런스가 너무 크므로 현재 1차 모델 타깃에서 제외하고 보관/분석용 컬럼으로 둔다.

## 5. 인밸런스 처리

train 데이터 기준으로 class weight를 계산했다.

계산 공식:

```text
class_weight = 전체 train 샘플 수 / (클래스 수 * 해당 클래스 샘플 수)
```

의미:

- 많이 나온 라벨은 weight가 작다.
- 적게 나온 라벨은 weight가 크다.
- 모델 학습 시 소수 라벨을 틀렸을 때 loss가 더 크게 반영된다.

현재 상태:

- class weight 계산 완료
- weighted train/test JSONL 생성 완료
- 실제 모델 학습 코드에서 class weight를 적용할 예정

## 6. 주요 평가지표

| 지표 | 사용 이유 |
|---|---|
| Accuracy | 전체 문항 중 맞힌 비율을 확인한다. 단, 인밸런스 데이터에서는 과대평가될 수 있다. |
| Macro F1 | 각 라벨의 F1을 동일한 비중으로 평균낸다. 소수 라벨 성능 확인에 중요하다. |
| Weighted F1 | 라벨별 support를 반영한 F1이다. 전체 분포 기준 성능을 확인한다. |
| Per-class Precision/Recall/F1 | 어떤 라벨을 잘 맞히고 못 맞히는지 확인한다. |
| Confusion Matrix | 어떤 라벨끼리 헷갈리는지 확인한다. |

메인 지표는 `Macro F1`로 둔다.  
Accuracy는 참고 지표로만 사용한다.

## 7. 1차 baseline 계획

1차 baseline은 `TF-IDF + Logistic Regression`으로 진행한다.

목적:

- 딥러닝 모델(KLUE/RoBERTa)을 쓰기 전 기준 성능을 만든다.
- 단어 중요도 기반의 가벼운 모델로도 어느 정도 분류가 되는지 확인한다.
