# 최신 트렌드 TOP5 및 모델 저장 작업 정리 - 2026-07-16

## 진행 목표

현재까지의 평가 결과를 바탕으로 다음 3가지를 정리한다.

1. walk-forward 결과 기반 최신 트렌드 TOP5 예측 데이터 생성
2. 70회차 기준 모델 3개와 78회차 기준 모델 3개 저장 준비
3. 결과 분석 및 다음 실행 작업 정리

## 1. TOP5 예측 데이터 정리

추가 학습 없이 기존 walk-forward 예측 결과를 사용했다.

입력 파일:

```text
C:/Users/Playdata/Downloads/eval_fixed_walk_forward_v2/eval_fixed_walk_forward_v2/walk_forward_all_rounds_combined_predictions.csv
```

생성 파일:

```text
ai/ml/reports/walk_forward_최신트렌드_TOP5_예측_분석_2026-07-16.md
ai/ml/reports/walk_forward_최신트렌드_TOP5_예측_전체.csv
ai/ml/reports/walk_forward_최신트렌드_TOP5_예측_회차별.csv
```

정리 기준:

| 기준 | 설명 |
| --- | --- |
| `pred_era` | 시대 예측 TOP5 |
| `pred_topic_train` | 통합 주제 예측 TOP5 |
| `pred_topic` | 세부 주제 예측 TOP5 |
| `pred_era_topic_train` | 시대 + 통합 주제 예측 TOP5, 최종 트렌드 분석의 핵심 |
| `pred_era_topic_train_topic` | 시대 + 통합 주제 + 세부 주제 예측 TOP5, 보조 분석 |

최종 트렌드 판단은 `pred_era_topic_train`을 중심으로 보는 것이 적절하다.

## 2. 저장할 모델 구조

저장할 모델은 총 6개다.

| 모델 세트 | 학습 데이터 | 저장 모델 | 용도 |
| --- | --- | --- | --- |
| `through_70` | 47~70회차 | `era`, `topic_train`, `topic` | 71~78회차 평가 재현용 |
| `through_78` | 47~78회차 | `era`, `topic_train`, `topic` | 최종 운영용 |

`through_70`은 평가 재현용이다.  
`through_78`은 앞으로 들어올 신규 문제 또는 79회차 이후 문제 예측용이다.

## 4. 모델 저장 관련 판단

기존 walk-forward 평가에서는:

```python
SAVE_MODEL_FIXED = False
SAVE_MODEL_WALK_FORWARD = False
```

였기 때문에 fixed holdout 모델과 walk-forward 임시 모델은 저장되지 않았다.

하지만 지금 전략에서는 walk-forward 24개 임시 모델을 저장하지 않는다.  
대신 관리 가능한 모델 세트 2개만 저장한다.

- 47~70 학습 모델 3개
- 47~78 학습 모델 3개

이 방식이 저장 용량, 설명 가능성, 운영 관리 측면에서 더 적절하다.

## 5. 분석 결론

- 71~78회차 최신 구간 평가에는 walk-forward 결과를 사용한다.
- 최신 트렌드 TOP5는 walk-forward 예측 CSV에서 바로 산출할 수 있다.
- 모델 저장은 walk-forward 전체 모델 24개보다 `through_70`, `through_78` 총 6개 모델이 적절하다.
- 최종 운영에서는 `through_78` 모델 세트를 사용한다.
- 71~78 평가 재현 또는 비교가 필요하면 `through_70` 모델 세트를 사용한다.
