# ML 작업 정리 - 2026-07-13

## 1. 오늘 작업 목적

오늘 작업의 핵심 목적은 한국사 기출문제의 출제 경향 분석 ML 모델에서 `통합 주제(topic_train)` 분류 성능을 개선할 수 있는지 확인하는 것이었다.

현재 ML은 최종 서비스에 바로 반영하기보다는, 과거 기출문제를 기반으로 시대와 주제의 출제 경향을 분석하고 최신 회차에서 그 경향이 어느 정도 재현되는지 확인하는 테스트 단계이다.

## 2. 사용 데이터

사용한 기본 데이터는 `ML_han_v1.json`에서 생성한 feature 데이터이다.

- 원천 데이터: `ai/ml/ML_han_v1.json`
- 기본 feature: `ai/ml/output/ml_han_features_v1.csv`
- core concept 포함 feature: `ai/ml/output/eval_splits_with_core_v1`
- 모델 평가용 split:
  - `split_era_topic_train_stratified_v1`: 시대 + 통합 주제 조합을 고려한 층화 평가
  - `split_time_v1`: 70회차까지 학습, 71~78회차 최신 회차 평가

평가 대상 라벨은 아래처럼 구분했다.

- `era`: 시대
- `topic`: 원래 주제 10개
- `topic_train`: 통합 주제 5개

현재 `topic_train`은 원래 라벨을 직접 바꾸는 것이 아니라, 모델 성능 확인을 위해 만든 통합 평가 라벨이다.

## 3. 모델 및 공통 설정

사용 모델은 `klue/roberta-base`이다.

모델 구조는 Hugging Face의 `AutoModelForSequenceClassification` 방식으로 사용하며, KLUE/RoBERTa의 사전학습된 언어 이해 능력 위에 분류 헤더를 붙여 `era`, `topic`, `topic_train` 같은 라벨을 예측하도록 파인튜닝했다.

주요 공통 설정은 다음과 같다.

| 항목 | 값 |
|---|---:|
| model | `klue/roberta-base` |
| max_length | 512 중심 실험 |
| batch_size | 8 또는 16 |
| learning_rate | 2e-5, 1e-5, 5e-6 |
| early stopping | 사용 |
| cross validation | 3-fold |
| 평가 지표 | accuracy, macro F1, weighted F1 |

불균형 라벨이 존재하므로 accuracy만 보지 않고 macro F1과 weighted F1을 함께 확인했다.

## 4. 주요 실험 결과

### 4.1 통합 주제 기준 실험

기준 실험은 `topic_train`, `split_era_topic_train_stratified_v1`, `text` 입력, class weight 적용 실험이다.

| 실험 | target | 입력 | 주요 변경 | accuracy | macro F1 | weighted F1 | 기준 대비 macro F1 |
|---|---|---|---|---:|---:|---:|---:|
| eval_v1 | topic_train | text | 기준 실험 | 0.6334 | 0.6171 | 0.6257 | - |
| eval_v2 | topic_train | text | max_length 512 -> 384 | 0.6085 | 0.5988 | 0.6035 | -0.0183 (-2.97%) |
| eval_v3 | topic_train | text | class weight 제거 | 0.6434 | 0.6222 | 0.6394 | +0.0051 (+0.83%) |
| choices_v1 | topic_train | text + choices | 선택지 포함 | 0.6234 | 0.6088 | 0.6231 | -0.0083 (-1.34%) |
| core_v1 | topic_train | text + core_concept | 핵심 개념 추가 | 0.6534 | 0.6467 | 0.6487 | +0.0296 (+4.80%) |
| core_v2 | topic_train | text + core_concept | class weight 제거 | 0.6409 | 0.6245 | 0.6333 | +0.0074 (+1.20%) |
| core_v3 | topic_train | text + core_concept | lr 5e-6, batch 16, epoch 10, class weight 적용 | 0.6608 | 0.6569 | 0.6507 | +0.0398 (+6.45%) |
| core_v4 | topic_train | text + core_concept | lr 1e-5, max epoch 30 | 0.6110 | 0.5933 | 0.5967 | -0.0238 (-3.86%) |

현재까지 `topic_train` 기준 가장 좋은 결과는 `core_v3`이다.

- accuracy: 0.6608
- macro F1: 0.6569
- weighted F1: 0.6507

기준 실험 대비 macro F1은 0.6171에서 0.6569로 상승했다.

- 절대 상승폭: +0.0398
- 상대 상승률: 약 +6.45%

### 4.2 원래 주제 평가

`topic`은 통합하지 않은 원래 주제 10개를 그대로 예측한 실험이다.

| 실험 | target | split | accuracy | macro F1 | weighted F1 |
|---|---|---|---:|---:|---:|
| eval_v4 | topic | split_era_topic_train_stratified_v1 | 0.5810 | 0.3348 | 0.5496 |

원래 주제 10개는 macro F1이 0.3348로 낮았다. 특히 `경제`, `군사`, `사회`, `외교`, `사상·종교`처럼 데이터 수가 적은 라벨에서 성능이 크게 떨어졌다.

따라서 현재 모델 성능 개선 단계에서는 `topic_train`으로 통합해 학습 안정성을 먼저 확인하고, 원래 주제는 별도 참고 지표로 유지하는 방향이 적절하다.

### 4.3 시대 평가

시대(`era`)는 통합 주제보다 성능이 더 안정적이었다.

| 실험 | target | split | accuracy | macro F1 | weighted F1 |
|---|---|---|---:|---:|---:|
| eval_v5 | era | split_era_topic_train_stratified_v1 | 0.7656 | 0.7127 | 0.7604 |
| eval_v6 | era | split_time_v1 | 0.7750 | 0.7008 | 0.7711 |

시대 예측은 accuracy와 weighted F1 기준으로 0.75 전후까지 도달했다. 다만 macro F1은 0.70 수준이라, `고조선`, `선사 시대`, `초기 국가`처럼 데이터가 적은 라벨의 영향이 남아 있다.

### 4.4 최신 회차 평가

`split_time_v1`은 70회차까지 학습하고 71~78회차를 평가하는 최신 회차 검증이다.

| 실험 | target | split | accuracy | macro F1 | weighted F1 |
|---|---|---|---:|---:|---:|
| eval_v6 | era | split_time_v1 | 0.7750 | 0.7008 | 0.7711 |
| eval_v7 | topic_train | split_time_v1 | 0.4750 | 0.4659 | 0.4704 |

시대는 최신 회차에서도 비교적 유지되지만, 통합 주제는 최신 회차에서 성능이 크게 떨어졌다.

이는 주제 라벨이 회차별 출제 경향 변화에 민감하거나, `정치`, `사건`, `인물`, `제도`의 경계가 문제 텍스트만으로 명확하지 않은 경우가 많기 때문으로 보인다.

## 5. 하이퍼파라미터 탐색 결과

작은 grid search를 통해 `learning_rate`와 `max_length`를 비교했다.

| 순위 | learning_rate | max_length | CV macro F1 | CV weighted F1 | 평균 best epoch |
|---:|---:|---:|---:|---:|---:|
| 1 | 2e-5 | 384 | 0.5702 | 0.5803 | 3.0 |
| 2 | 1e-5 | 384 | 0.5533 | 0.5711 | 3.7 |
| 3 | 2e-5 | 512 | 0.5507 | 0.5677 | 2.3 |

grid search만 보면 `lr=2e-5`, `max_length=384`가 가장 높았다. 하지만 실제 holdout 평가에서는 `core_concept`를 포함하고 `lr=5e-6`, `batch_size=16`, `class weight=True`를 적용한 `core_v3`가 가장 좋았다.

따라서 단순 grid search 결과만으로 최종 파라미터를 고정하기보다는, 입력 데이터 구성과 holdout 성능을 함께 봐야 한다.

## 6. 좋아진 작업

### 6.1 core_concept 추가

`text_with_core` 입력을 사용해 문제 텍스트에 핵심 개념을 추가했을 때 성능이 가장 의미 있게 올랐다.

- 기준 macro F1: 0.6171
- core_v1 macro F1: 0.6467
- 상승폭: +0.0296
- 상승률: 약 +4.80%

핵심 개념은 주제 분류에 필요한 단서를 직접 제공하므로, 모델이 문제의 주제 방향을 더 잘 잡은 것으로 보인다.

### 6.2 낮은 learning rate + batch size 증가

`core_v3`에서 learning rate를 5e-6으로 낮추고 batch size를 16으로 올렸을 때 가장 좋은 결과가 나왔다.

- macro F1: 0.6569
- 기준 대비 상승률: 약 +6.45%

학습률을 낮추면서 업데이트가 안정화되었고, batch size 증가로 gradient가 조금 더 안정적으로 계산된 것으로 볼 수 있다.

### 6.3 class weight 적용

class weight는 실험마다 무조건 좋은 것은 아니었지만, `core_concept`와 낮은 learning rate를 함께 쓴 `core_v3`에서는 가장 좋은 성능을 냈다.

현재 통합 주제에서도 `정치` 라벨이 상대적으로 어렵기 때문에, class weight는 완전히 제거하기보다 조건별로 비교하는 것이 좋다.

## 7. 나빠진 작업

### 7.1 선택지 포함

선택지를 추가한 `choices_v1`은 성능이 오히려 떨어졌다.

- 기준 macro F1: 0.6171
- choices_v1 macro F1: 0.6088
- 변화: -0.0083

선택지에는 문제 풀이에는 도움이 되는 정보가 있지만, 주제 분류에는 잡음이 될 수 있다. 특히 선택지에 여러 시대와 주제가 섞이면 모델이 핵심 지문보다 선택지 단어에 끌릴 가능성이 있다.

### 7.2 max_length 384 단독 변경

`eval_v2`에서 max_length를 384로 줄였을 때 성능이 떨어졌다.

- 기준 macro F1: 0.6171
- eval_v2 macro F1: 0.5988

문제 지문이 긴 경우 핵심 단서가 잘릴 수 있으므로, 현재는 max_length 512를 유지하는 편이 낫다.

### 7.3 max epoch 30 + learning rate 1e-5

`core_v4`는 max epoch를 30까지 늘렸지만, 실제 final epoch는 early stopping으로 5에서 멈췄고 성능은 떨어졌다.

- core_v3 macro F1: 0.6569
- core_v4 macro F1: 0.5933
- 변화: -0.0636

epoch를 크게 늘리는 것 자체가 성능 향상을 보장하지 않는다. validation loss가 특정 시점 이후 나빠지면 early stopping이 멈추지만, learning rate나 class weight 조합에 따라 이미 일반화 성능이 떨어질 수 있다.

## 8. 오분류 검토 작업

모델 성능이 0.75 이상으로 오르지 않는 이유가 단순 파라미터 문제가 아니라 라벨 기준의 모호성일 수 있다고 판단했다.

그래서 오늘 다음 작업을 추가로 진행했다.

- 기존 라벨은 유지
- 라벨 기준표만 재정의
- 오분류 일부를 우선 검토할 수 있도록 CSV 생성

생성한 파일은 다음과 같다.

- `ai/ml/output/topic_label_review_v1/topic_label_criteria_v1.md`
- `ai/ml/output/topic_label_review_v1/topic_misclassification_review_v1.md`
- `ai/ml/output/topic_label_review_v1/topic_misclassification_priority_v1.csv`
- `ai/ml/output/topic_label_review_v1/topic_misclassification_all_v1.csv`

검토 결과 대상은 다음과 같다.

- 평가셋 전체: 401건
- 오분류: 136건
- 우선 검토 샘플: 80건

우선 검토 대상은 `정치 -> 사건`, `정치 -> 인물`, `정치 -> 제도`, `제도 -> 정치`처럼 라벨 기준이 흔들릴 가능성이 큰 케이스를 먼저 뽑았다.

## 9. 현재 판단

현재 수치만 보면 `era`는 실사용 가능성에 가까워지고 있지만, `topic_train`은 아직 개선이 필요하다.

- 시대 예측: weighted F1 약 0.76~0.77
- 통합 주제 예측: 최고 weighted F1 약 0.65
- 원래 주제 예측: macro F1 약 0.33으로 낮음

`topic_train` 성능을 0.75 이상으로 올리려면 단순 파라미터 튜닝만으로는 한계가 있어 보인다. 라벨 기준을 다시 점검하고, 특히 `정치`, `사건`, `인물`, `제도`의 경계를 명확히 해야 한다.
