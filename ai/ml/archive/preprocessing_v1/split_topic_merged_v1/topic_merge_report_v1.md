## 목적

- 원본 `topic`은 보존합니다.
- 모델 학습용 통합 라벨 `topic_train`을 추가합니다.

## 사용 방법

```text
era 모델: era 사용
topic 모델: topic 대신 topic_train 사용
question_type 모델: 현재 성능/라벨 쏠림 문제로 제외 검토
```

## 주의

- 예측 결과가 `정치`라면 원본의 정치/경제/사회/군사/외교가 포함된 학습용 라벨입니다.
- 예측 결과가 `문화`라면 원본의 문화/사상·종교가 포함된 학습용 라벨입니다.
- 원본 세부 topic 해석이 필요하면 `topic` 컬럼을 함께 확인해야 합니다.
