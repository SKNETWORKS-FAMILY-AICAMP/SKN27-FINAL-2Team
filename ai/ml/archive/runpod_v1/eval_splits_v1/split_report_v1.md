# ML Evaluation Splits v1

## 목적

- 시간 기반 평가셋과 `era + topic_train` 조합 기준 층화추출 평가셋을 생성했습니다.
- 하나의 split 파일로 `era`, 원본 `topic`, 통합 `topic_train`을 모두 평가할 수 있습니다.
- `question_type`은 현재 평가 대상에서 제외합니다.
