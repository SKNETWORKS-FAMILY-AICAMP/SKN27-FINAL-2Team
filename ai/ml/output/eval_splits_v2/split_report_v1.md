# ML Evaluation Splits v1

## 목적

- 시간 기반 평가셋과 `era + topic_train` 조합 기준 층화추출 평가셋을 생성했습니다.
- 하나의 split 파일로 `era`, 원본 `topic`, 통합 `topic_train`을 모두 평가할 수 있습니다.
- `question_type`은 현재 평가 대상에서 제외합니다.

## 입력/출력

- 입력 파일: `ai/ml/output/split_topic_merged_v2/full_features_topic_merged_v2.json`
- 출력 폴더: `ai/ml/output/eval_splits_v2`
- random_state: 42
- stratified test ratio: 0.25

## 다음 단계

1. RunPod 학습 코드는 이 split 폴더의 `train.json`, `test.json`을 입력으로 받도록 작성합니다.
2. 먼저 `split_era_topic_train_stratified_v1`로 `topic_train` 성능 개선 실험을 진행합니다.
3. 같은 split에서 원본 `topic` 모델도 학습해 원본 주제 성능을 함께 확인합니다.
4. 시간 기반 split은 실제 최신 회차 예측 성능 비교용으로 유지합니다.
