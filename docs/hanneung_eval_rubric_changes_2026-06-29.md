# 한능검 SLLM 평가표 수정 내역 2026-06-29

## 1. 정리 기준

이 문서는 오늘 수정한 평가표와 API 실험 결과를 **우리가 실제로 돌린 평가 단위** 기준으로 정리한 문서이다.

평가 단위는 아래 순서로 본다.

| 순서 | 평가 단위 | 역할 |
|---:|---|---|
| 1 | Gate | 문항이 성립하는지 먼저 판정 |
| 2 | 문제 10점 | Gate PASS 문항의 난이도와 선택지 품질 채점 |
| 3 | 해설 5점 | Gate PASS 문항의 해설 품질 채점 |
| 4 | 최종 판정 | accept, revise, repair, regenerate, needs_verification 결정 |
| 5 | 결과 출력 | 실패 Gate와 수리 대상을 표에 표시 |

관련 기준 본문은 `docs/hanneung_sllm_eval_rubric_v1_8.md`이다.

## 2. Gate 평가 단위

Gate는 점수보다 먼저 적용한다. 하나라도 FAIL이면 문제 10점과 해설 5점은 채점하지 않는다.

오늘 정리한 Gate는 6개이다.

| Gate | 평가 단위 | 오늘 수정/확정한 내용 |
|---|---|---|
| G1 | 입력·형식 성립 | 발문, 선택지 5개, 정답, target_score가 있는지 확인 |
| G2 | 발문·선지 판독 가능성 | 문장 깨짐, 추출 찌꺼기, 선택지에 페이지 머리말·꼬리말이 섞인 경우 FAIL |
| G3 | 정답 성립성 및 유일성 | 발문 조건을 만족하는 선택지가 0개 또는 2개 이상이면 FAIL |
| G4 | 발문·자료 사실성 | 발문·자료의 핵심 단서가 역사 사실과 명백히 충돌하면 FAIL |
| G5 | 오답 역사 사실성 | 오답 선지 자체가 역사적으로 성립하는지 검증 |
| G6 | 정답 노출·복사·외형 편향 | 발문·자료와 정답 선지가 문장 매칭으로 연결되면 FAIL |

### 2.1 Gate FAIL 처리 변경

기존에는 Gate FAIL이면 모두 `regenerate`였다. 오늘 수정 후에는 아래처럼 나눈다.

| 실패 Gate | 최종 처리 | 이유 |
|---|---|---|
| G1/G2만 실패 | repair | 추출 정리나 형식 복구로 살릴 수 있음 |
| G5만 실패 | repair | 오류 오답 선지만 교체하면 되는 경우가 많음 |
| G6만 실패 | repair | 발문 단서 또는 정답 선지 표현을 바꾸면 살릴 수 있음 |
| G1/G2/G5/G6 조합 | repair | 부분 수리 가능성이 높음 |
| G3 포함 | regenerate | 정답 후보 구조가 흔들림 |
| G4 포함 | regenerate | 발문·자료 고증이 흔들림 |
| Gate uncertain | needs_verification | 후속 검증 필요 |

## 3. G5 오답 역사 사실성 평가 단위

오늘 가장 많이 수정한 부분은 G5이다.

### 3.1 G5가 잡아야 하는 것

| 경우 | 판정 |
|---|---|
| 오답 선지가 역사적으로 존재하지 않는 사실을 말함 | G5 FAIL |
| 서로 다른 주체·사건·결과를 한 문장으로 허위 결합 | G5 FAIL |
| 실제로 없는 계승·해체·인과·순서 관계를 만듦 | G5 FAIL |
| 시기상 존재할 수 없는 주체가 사건을 지원·탄압·주도했다고 함 | G5 FAIL |

### 3.2 G5가 잡으면 안 되는 것

| 경우 | 판정 |
|---|---|
| 다른 인물·단체·시대의 실제 역사 사실 | 정상 오답 |
| 발문 주체에 대입하면 틀리지만, 다른 실제 주체의 사실로 성립함 | 정상 오답 |
| 발문 조건과 맞지 않을 뿐 문장 자체는 역사적으로 맞음 | 정상 오답 |

### 3.3 오늘 확정한 예시

| 선지 유형 | 예시 | 판정 |
|---|---|---|
| 정상 오답 | `2·8 독립 선언서를 발표하였다` | 일본 유학생의 실제 사실이므로 G5 PASS |
| 정상 오답 | `봉오동 전투에서 일본군을 격파하였다` | 대한 독립군 등의 실제 사실이므로 G5 PASS |
| 정상 오답 | `조선 총독부에 국권 반환 요구서를 제출하려 하였다` | 독립 의군부 관련 실제 사실이므로 G5 PASS |
| 허위 관계 | `한인 애국단으로 발전적으로 해체되었다` | 실제 계승·해체 관계가 아니므로 G5 FAIL |
| 허위 시기·지원 | `신간회의 지원을 받아 전개되었다` | 신간회 창립 시기상 성립하지 않아 G5 FAIL |
| 허위 인과 | `원산 총파업으로 이어졌다` | 직접 연결 관계가 성립하지 않으면 G5 FAIL |

### 3.4 G5 구조화 필드

LLM이 오답을 멋대로 참인 문장으로 바꿔 평가하지 못하게 아래 필드를 사용한다.

| 필드 | 역할 |
|---|---|
| `original_choice_text` | 입력 선택지 원문 |
| `historical_proposition` | 선택지 자체를 역사 명제로 환원 |
| `stem_applied_claim` | 발문 조건을 대입했을 때의 주장 |
| `claim_parts` | 주체, 행위, 대상, 시기, 결과, 인과·순서 분해 |
| `whole_claim_validity` | 문장 전체가 역사 명제로 성립하는지 |
| `g5_error_classification` | 정상 오답인지, 없는 사실로 만든 오답인지 분류 |

## 4. G6 정답 노출 평가 단위

G6는 “쉬운 문제”를 모두 탈락시키는 항목이 아니다. 다만 정답 선지만 발문·자료 표현을 거의 그대로 반복해 문장 매칭으로 정답을 고를 수 있으면 FAIL이다.

| 하위 단위 | 평가 내용 |
|---|---|
| G6-1 | 정답명·핵심명이 발문에 직접 노출됨 |
| G6-2 | 발문·자료의 핵심 진술이 정답 선지에 복사 또는 의역됨 |
| G6-3 | 정답 선지만 길이, 구체성, 발문 표현 반복, 문장 형식에서 튐 |

오늘 확인한 애매 사례는 38번이다.

| 문항 | 논점 | 현재 처리 |
|---:|---|---|
| 38 | 발문에 `학교`, `독립군 양성`이 있고 정답에 `신흥 무관 학교`, `독립군을 길렀다`가 반복됨 | 보수적으로 G6 FAIL, 최종 repair |

향후 필요하면 G6는 `명백한 정답 노출`과 `강한 단서로 인한 난이도 저하`를 더 나눌 수 있다. 하지만 오늘 기준에서는 G6를 보수적으로 유지했다.

## 5. 문제 10점 평가 단위

문제 10점은 Gate PASS 문항에만 적용한다.

| 평가 단위 | 배점 | 평가 내용 |
|---|---:|---|
| 목표 난이도 적합성 | 4점 | 실제 풀이 난이도가 target_score와 맞는가 |
| 선택지 품질 | 6점 | 선택지 비교 단위, 중복·포함 관계, 유효 매력 오답이 적절한가 |

### 5.1 목표 난이도 적합성 4점

아래 4개 요소를 target_score 기준과 비교한다.

| 요소 | 의미 |
|---|---|
| 단서 묶음 수 | 정답 도출에 필요한 독립 단서 수 |
| 단서 유형 | 직접 단서, 대표 추론 단서, 우회·사료 단서 |
| 풀이 단계 | 식별, 비교, 관계 판단 |
| 지식 깊이 | 대표 개념, 심화 기본 개념, 세부 개념 |

### 5.2 선택지 품질 6점

| 세부 단위 | 배점 | 평가 내용 |
|---|---:|---|
| 응답 범주 적합성 | 1점 | 선택지 5개가 발문이 요구하는 응답 범주에 맞는가 |
| 중복·포함 관계 없음 | 1점 | 선택지끼리 같은 내용 반복이나 포함 관계가 없는가 |
| 유효 매력 오답 수 | 4점 | 발문 단서를 적용한 뒤에도 비교 후보로 남는 오답이 충분한가 |

### 5.3 target_score별 유효 매력 오답 기준

| target_score | 기준 |
|---:|---|
| 1점 | 유효 매력 오답 0개여도 허용 |
| 2점 | 2개 이상이면 만점, 1개면 부분점, 0개면 감점 |
| 3점 | 3개 이상이면 만점, 2개 또는 1개면 부분점, 0개면 큰 감점 |

오늘 API 결과에서 36번과 39번은 Gate PASS였지만 유효 매력 오답이 부족해 `revise`로 남았다.

## 6. 해설 5점 평가 단위

해설 5점은 기존 5개 항목을 유지했다. Gate PASS 문항에만 적용한다.

| 평가 단위 | 배점 | 기준 |
|---|---:|---|
| 정답 근거 제시 | 1점 | 정답 선지가 정답인 이유를 제시 |
| 단서 사용 설명 | 1점 | 발문·자료의 어떤 단서로 정답을 도출했는지 설명 |
| 오답 배제 설명 | 1점 | 오답 중 최소 2개 이상 배제 이유 설명 |
| 정답-해설 일치 | 1점 | 해설 정답 번호와 표시 정답 일치 |
| 해설 사실성 | 1점 | 해설에 명백한 역사 오류나 무관한 설명 없음 |

Gate FAIL이면 해설 점수도 null로 둔다. 문제 자체가 성립하지 않으면 해설 품질 점수를 따로 주지 않는다.

## 7. 최종 판정 평가 단위

오늘 최종 판정 체계를 아래처럼 정리했다.

| 최종 판정 | 의미 |
|---|---|
| accept | 그대로 사용 가능 |
| accept_with_warning | 사용 가능하지만 약한 경고 있음 |
| revise | Gate는 통과했지만 난이도·선지 품질·해설 품질 수정 필요 |
| repair | Gate FAIL이지만 일부 수정으로 살릴 수 있음 |
| regenerate | 정답 구조나 발문·자료 고증이 흔들려 새로 만드는 편이 나음 |
| needs_verification | LLM만으로 확정하기 어렵고 후속 검증 필요 |

## 8. 결과 출력 평가 단위

결과표는 기존보다 운영용으로 바꿨다.

추가한 컬럼은 다음과 같다.

| 컬럼 | 의미 |
|---|---|
| 실패 Gate | 어떤 Gate가 실패했는지 |
| 수리/재생성 대상 | 어떤 부분을 고치면 되는지 |
| 판정 | repair/regenerate/revise/accept 등 최종 처리 |

이 변경으로 `regenerate`처럼만 보이던 문항들이 실제로는 대부분 `repair` 가능한 문항임을 확인할 수 있게 되었다.

## 10. 코드 후처리 평가 단위

API 실험 코드에는 LLM 판정 흔들림을 줄이기 위한 후처리가 추가되었다. 특정 역사 키워드를 넣어 특정 문항만 잡는 방식은 사용하지 않았다.

| 후처리 단위 | 역할 |
|---|---|
| 형식 검사 | 선택지 5개, 정답 대응, 빈 선택지 확인 |
| 추출 찌꺼기 검사 | `[[PAGE]]`, 문제지 머리말·꼬리말 등 감지 |
| 정답 노출 검사 | 발문과 정답 선지만 반복되는 핵심어·구절 탐지 |
| G5 일관성 검사 | 오답 역사 오류 유형과 선택지 원문 대조 |
| G5 오판 해제 | 정상 오답을 LLM이 G5 FAIL로 둔 경우 해제 |
| 선택지 품질 재계산 | 유효 매력 오답 수 기반으로 점수 재산정 |
| repair/regenerate 분기 | 실패 Gate 조합에 따라 최종 판정 조정 |

## 11. 남은 쟁점

| 쟁점 | 현재 처리 |
|---|---|
| G6 애매 사례 | 보수적으로 Gate FAIL, repair로 보냄 |
| RAG 검증 | 지금 평가지표에는 직접 넣지 않고, 파인튜닝·파이프라인 단계에서 연결 예정 |
| 추출 찌꺼기 | 현재 G2에서 잡지만 전처리에서 제거하는 편이 더 좋음 |
| 자동 repair 생성 | 현재는 수리 대상만 표시, 실제 수정 문장 생성은 후속 단계 |
