# 2026-06-27 문제풀이/진단평가/노트 변경 사항

## 1. 진단평가 진행 저장/불러오기 안정화

- 진단평가 새 시작 시 이전 `localStorage` 진행 데이터가 먼저 복원될 수 있던 문제를 수정했습니다.
- 진단평가 진행 중 저장 세션은 최신 1개만 불러오도록 정리했습니다.
- 진단평가 진행 저장 버튼 오류를 수정했습니다.
- 진단평가도 문제풀이와 동일하게 저장된 세션을 `/question/`의 문제 불러오기 모달에서 확인할 수 있습니다.

참고 API:
- `GET /diagnosis/api/sessions/in-progress/`
- `GET /diagnosis/api/session/<session_id>/`
- `PATCH /diagnosis/api/session/<session_id>/answer/`

## 2. 문제풀이 저장/불러오기 모달 개선

- 문제 생성 페이지의 `문제 불러오기`를 모달 방식으로 변경했습니다.
- 저장된 문제지를 세 그룹으로 분리했습니다.
  - 진단 평가
  - 문제 풀이
  - 학습 계획 문제 풀이
- 모달 배경을 진한 반투명 배경으로 변경해 뒤 화면과 구분되도록 했습니다.
- 각 목록 영역에 내부 스크롤을 추가했습니다. 학습 계획 문제 풀이 세션이 많아도 모달이 깨지지 않습니다.

참고 API:
- `GET /question/api/sessions/in-progress/`
- `GET /diagnosis/api/sessions/in-progress/`

## 3. 학습 계획 문제풀이 연결 기반 추가

- 문제 생성 API에 `generation_mode = study_plan` 흐름을 추가했습니다.
- 학습 플래너에서 `studyPlanId`, `studyPlanBlockId`를 전달하면 해당 학습계획 블록 조건으로 문제를 생성합니다.
- 생성된 `solve_records`에는 아래 값이 저장됩니다.
  - `studyplan_id`
  - `study_plan_block_id`
- 학습 계획 문제풀이 세션은 `solve_sessions.session_type`은 `practice`이고, `solve_records.studyplan_id` 존재 여부로 학습계획 세션을 구분합니다.

문제 생성 요청에 필요한 핵심 값:

```json
{
  "generation_mode": "study_plan",
  "studyplan_id": 1,
  "study_plan_block_id": "block-id"
}
```

주의:
- 마이페이지의 오늘의 계획 `문제 풀기`는 문제 생성 페이지를 거치지 않고 바로 `/question/exam/?new=1`로 이동하는 구조입니다.
- 문제 생성 페이지의 `학습 계획 문제 풀기` 카드는 학습 플래너가 조건을 넘긴 상태에서 사용할 수 있는 진입 UI입니다.

## 4. 문제풀이 화면 난이도 표시 변경

- 문제풀이 화면에서 유형 옆에 보이던 `3점/2점/1점` 표시를 `상/중/하`로 변경했습니다.
- 진단평가는 기존처럼 `3점/2점/1점` 배점 표시를 유지합니다.
- DB 값과 채점 로직은 그대로 `q_score`를 사용합니다.

표시 기준:
- `3점` -> `상`
- `2점` -> `중`
- `1점` -> `하`

## 5. 결과 페이지 표시 개선

- 문제풀이 결과 페이지의 `현재 수준` 영역을 `맞은 개수`로 변경했습니다.
  - 예: `10 / 50`
- 문제풀이 결과의 `총점 / 정답률` 영역은 `정답률`만 표시하도록 변경했습니다.
- 진단평가 결과는 기존처럼 예상 급수, 총점/정답률 중심으로 유지합니다.

## 6. 랜덤 선택지 번호와 노트 표시 불일치 수정

- 문제풀이에서는 선택지가 랜덤으로 섞입니다.
- 결과 페이지는 랜덤 화면 번호를 기준으로 정답/사용자 답안을 보여주고 있었지만, 노트 화면은 DB 원본 번호를 사용해 번호가 다르게 보이는 문제가 있었습니다.
- 노트에서도 `session_id + question_id` 기준으로 동일한 선택지 랜덤 순서를 재계산해 결과 페이지와 같은 번호를 보여주도록 수정했습니다.
- 진단평가는 선택지 랜덤 섞기를 적용하지 않으므로 기존 번호를 유지합니다.

## 7. 노트 페이지 UI/필터 개선

- `오답노트` 명칭을 `노트` 흐름으로 정리했습니다.
- 노트는 현재 두 탭 중심입니다.
  - 오답 노트
  - 저장 노트
- 필터 UI를 모달 형태로 변경했습니다.
- 필터 모달은 바깥 영역을 클릭하면 닫히도록 수정했습니다.
- 세션 필터 옵션에 날짜와 세션 유형이 같이 보이도록 변경했습니다.
  - 예: `2026-06-27 · 진단평가 (50문항)`
  - 예: `2026-06-27 · 문제풀이 (10문항)`

## 8. 공통 결과 페이지 방향

- 문제풀이와 진단평가는 공통 결과 페이지를 사용하되, 표시 내용은 모드별로 다르게 처리합니다.
- 공통 영역:
  - 문항별 결과
  - 사용자 답안
  - 실제 정답
  - 풀이 시간
  - 해설
  - 오답 설명
  - 핵심 개념
  - 노트 저장
- 진단평가 전용:
  - 예상 급수
  - 진단 분석
- 문제풀이 전용:
  - 맞은 개수
  - 정답률
  - 저장 노트 연동

## 9. 팀원 확인 필요 사항

### 학습계획 세션 라벨

현재 학습계획 문제풀이는 DB상 `session_type = practice`로 저장되고, `solve_records.studyplan_id`로 구분합니다.

따라서 화면에서 학습계획 문제풀이를 정확히 `학습 계획 문제 풀이`로 표시하려면, 세션 목록을 만들 때 해당 세션의 record에 `studyplan_id`가 있는지 확인해야 합니다.

현재 확인된 현상:
- 노트 세션 필터에서 학습계획 문제풀이가 `문제풀이`로 보일 수 있습니다.
- 이 경우 `wrong_note` payload 생성 시 `studyplan_id` 기반 세션 라벨 분기 추가가 필요합니다.

### CSS 캐시

이번 변경은 CSS/JS 변경이 많습니다. 화면 반영이 안 되면 아래 순서로 확인하면 됩니다.

1. `Ctrl + F5` 강력 새로고침
2. 개발자도구 `Network` 탭에서 `Disable cache` 체크 후 새로고침
3. 그래도 안 되면 `runserver` 재시작
