# v40 vs v41 수동 평가 비교 보고서

## 1. 평가 방식

- 평가 대상: `generated_predictions (8).jsonl` v40 첫 10문항, `generated_predictions (11).jsonl` v41 첫 10문항
- 평가 기준: `docs/hanneung_sllm_eval_rubric_v1_8.md`
- 평가자: Codex 수동 검수
- API judge 사용 여부: 사용하지 않음
- 점수 체계: Gate + 선택지 품질 6점
- Gate FAIL 처리: 평가표 원칙에 따라 실효 점수 0점
- 목표 난이도 적합성 4점은 이번 비교 점수에서 제외한다. 이번 실험은 발문·자료·target_score가 주어진 상태에서 생성된 선택지 품질을 비교하는 것이므로, 점수는 선택지 품질 6점만 사용한다.

## 2. 입력 매칭 결과

v40과 v41의 첫 10문항 중 같은 입력으로 비교 가능한 문항은 8개이다.

| 문항 | 입력 동일 여부 | 비고 |
|---:|---|---|
| 1 | 동일 | 진흥왕 |
| 2 | 동일 | 후백제 |
| 3 | 동일 | 거문도 |
| 4 | 다름 | v40은 양세봉 자료와 몽골 예쿠 정답 근거가 충돌, v41은 양세봉 근거로 수정됨 |
| 5 | 동일 | 한국 독립당 선언문 |
| 6 | 동일 | 사화 순서 배열 |
| 7 | 동일 | 조선 후기 화폐 부족 상황 |
| 8 | 동일 | 헐버트·조지 루이스 쇼 보기 조합 |
| 9 | 동일 | 위만 조선 |
| 10 | 다름 | v40은 `이후의 사실`, v41은 `왕의 재위 기간`으로 조건이 바뀜 |

따라서 전체 10문항 비교는 v41 최신 산출물의 품질 확인으로는 유효하지만, 순수한 동일 입력 모델 개선 비교로는 1,2,3,5,6,7,8,9번만 사용해야 한다.

## 3. 전체 요약

### 3.1 전체 10문항 기준

| 버전 | Gate PASS | Gate FAIL | 선지품질 실효 점수 | 평균 선지품질 점수 | PASS 문항 평균 |
|---|---:|---:|---:|---:|---:|
| v40 | 6/10 | 4/10 | 32/60 | 3.2/6 | 5.33/6 |
| v41 | 8/10 | 2/10 | 44/60 | 4.4/6 | 5.50/6 |

전체 기준으로는 v41이 v40보다 좋아졌다. 다만 이 개선의 핵심은 입력이 바뀐 4번과 10번에서 나온다.

### 3.2 동일 입력 8문항 기준

| 버전 | Gate PASS | Gate FAIL | 선지품질 실효 점수 | 평균 선지품질 점수 | PASS 문항 평균 |
|---|---:|---:|---:|---:|---:|
| v40 | 6/8 | 2/8 | 32/48 | 4.0/6 | 5.33/6 |
| v41 | 6/8 | 2/8 | 32/48 | 4.0/6 | 5.33/6 |

동일 입력만 놓고 보면 v40과 v41은 사실상 동률이다. 즉, v41 자체 산출물은 더 좋아졌지만, 그것이 모델 변경 때문인지 입력 수정 때문인지는 분리해서 말해야 한다.

## 6. API judge 결과와 수동 평가 차이

이번 수동 평가는 기존 `gpt-4.1-mini` judge 결과보다 아래 지점에서 다르게 본다.

| 문항 | API judge 경향 | 수동 판단 |
|---:|---|---|
| 4 | v41을 G6 FAIL로 볼 가능성이 있음 | G6 경계는 있지만 `영릉가 전투` 지식이 필요하므로 PASS |
| 5 | 실행마다 PASS/FAIL이 흔들림 | Gate PASS, 다만 3점 문항으로는 오답 매력도가 낮아 2/6점 |
| 7 | 일부 실행에서 G1/G3 FAIL로 흔들림 | 정상 문항으로 PASS, 6/6점 |
| 10 | G6 또는 G2를 과하게 잡을 수 있음 | v41은 발문 조건이 `왕의 재위 기간`으로 명확해 PASS |

결론적으로 `gpt-4.1-mini` judge는 예비 자동 필터로는 쓸 수 있지만, 최종 비교 수치로 그대로 발표하기에는 흔들림이 있다. 특히 G5/G6와 정답 유일성에서 수동 재검수가 필요하다.

## 7. 결론

v41 최신 산출물의 첫 10문항 품질은 v40 전체 첫 10문항보다 좋아졌다. 수치상으로는 Gate PASS가 6/10에서 8/10으로 올라갔고, 선지품질 6점 기준 평균 실효 점수도 3.2점에서 4.4점으로 상승했다.

다만 엄밀한 동일 입력 비교에서는 8문항 기준 v40과 v41이 모두 32/48으로 동률이다. 따라서 발표나 보고서에서는 `v41이 최신 입력 세트에서 더 높은 품질을 보였다`고 말하는 것이 안전하며, `같은 입력에서 모델 자체가 개선되었다`고 단정하면 안 된다.

실무적으로는 v41 기준으로 1번과 3번은 재생성이 필요하고, 5번은 Gate는 통과하지만 3점 문항으로 쓰려면 오답을 더 가까운 시기·주제의 선택지로 repair해야 한다.
