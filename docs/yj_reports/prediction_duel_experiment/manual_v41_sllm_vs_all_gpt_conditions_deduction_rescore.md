# v41 SLLM vs GPT 조건별 감점식 재평가

## 1. 평가 범위

- 대상: v41 SLLM 첫 10문항, GPT 비교군 첫 10문항
- GPT 조건: 기본, H1, H2, H3
- GPT 모델: gpt-4.1-mini, gpt-4.1, gpt-5
- 평가자: Codex 수동 검수
- API judge: 사용하지 않음
- 목표 난이도 4점: 제외

이 실험은 전체 문항 생성 평가가 아니라 선지 생성 품질 비교에 가깝다. 따라서 `목표 난이도 적합성 4점`은 제외하고, 기존과 동일하게 `Gate + 선택지 품질 6점`만 평가한다.

## 2. 감점식 기준

Gate를 먼저 본다. Gate FAIL이면 선택지 품질 점수를 매기지 않고 실효 점수는 0점이다.

Gate PASS 문항은 6점에서 시작해 아래 결함만 감점한다.

| 감점 대상 | 감점 기준 |
|---|---|
| 발문 응답 범주 불일치 | 선택지 1개가 발문이 요구한 응답 범주에서 벗어나면 -1점. 선택지 세트가 전반적으로 다른 형식이면 G2/G3 검토 |
| 중복·포함 관계 | 약한 중복·포함 1쌍이면 -1점. 복수 정답 가능성을 만들면 G3 FAIL |
| 유효 매력 오답 부족 - 1점 문항 | 같은 시대권 또는 같은 주제권의 정상 오답 3~4개면 감점 없음, 2개면 -1점, 1개면 -2점, 0개면 -4점 |
| 유효 매력 오답 부족 - 2점 문항 | 유효 매력 오답 2개 이상이면 감점 없음, 1개면 -1점, 0개면 -4점 |
| 유효 매력 오답 부족 - 3점 문항 | 유효 매력 오답 3개 이상이면 감점 없음, 2개면 -1점, 1개면 -2점, 0개면 -4점 |
| 정답 외형 편향 | 정답 선지만 길이·구체성·형식에서 약하게 튀면 -1점. 문장 매칭이나 강한 외형 편향으로 정답 추정이 가능하면 G6 FAIL |

동일한 원인으로 중복 감점하지 않는다. 역사 오류, 복수 정답, 정답 직접 노출, 정답 선지 복사는 점수 감점이 아니라 Gate에서 처리한다.

## 5. 해석

감점식으로 바꿔도 순위는 바뀌지 않는다.

1. gpt-4.1-mini 계열은 SLLM v41보다 낮다. 주된 원인은 G5 오답 역사 사실성, G6 정답 노출·외형 편향, 자료 없는 지도형 문항 대응 실패다.
2. gpt-4.1 기본과 gpt-5 계열은 SLLM과 동급 이상이다. 특히 SLLM이 실패한 1번 문항을 상위 GPT는 발문 구조를 바꿔 살린 점이 크다.
3. H1/H2/H3 힌트가 항상 성능을 올리지는 않았다. 더 많은 기준을 주면 일부 모델은 과설명형 정답 선지, 형식 불균형, 불필요한 문장 확장으로 오히려 G6 위험이 커졌다.
4. SLLM의 장점은 최고 성능 절대 우위가 아니라, mini급 GPT 대비 낮은 비용에서 안정적인 선택지 형식과 Gate 통과율을 보인다는 점이다.

## 6. 발표용 요약

```text
선택지 품질을 감점식으로 재평가해도 기존 결과와 총점 변동은 없었다. 
이는 기존 6점 합산식이 사실상 결함별 감점식과 같은 요소를 보고 있었기 때문이다.
SLLM v41은 gpt-4.1-mini 대비 안정적으로 우세하지만, gpt-4.1 기본 및 gpt-5 일부 조건은 SLLM을 넘어선다.
따라서 발표에서는 "최고 성능 모델을 이겼다"가 아니라 "저비용 SLLM이 mini급 GPT보다 안정적이며, 상위 GPT와 비교해도 일부 조건에서는 경쟁 가능한 선택지 생성 품질을 보였다"로 말하는 것이 방어 가능하다.
```
