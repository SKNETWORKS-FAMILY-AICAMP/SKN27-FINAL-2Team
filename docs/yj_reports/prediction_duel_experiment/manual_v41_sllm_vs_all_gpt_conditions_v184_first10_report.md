# v41 SLLM vs GPT 조건별 10문항 재평가 보고서 v1.8.4

## 1. 평가 범위

- 대상: v41 SLLM 첫 10문항, GPT 비교군 첫 10문항
- GPT 모델: gpt-4.1-mini, gpt-4.1, gpt-5
- GPT 조건: 기본, H1, H2, H3
- 평가 기준: `docs/hanneung_sllm_eval_rubric_v1_8.md` v1.8.4
- 평가 방식: Codex 수동 검수
- API judge: 사용하지 않음

이 비교는 기존 GPT 대결 실험과 동일하게 `Gate + 선택지 품질 6점`만 본다. 생성 대상이 선지 중심 산출물이므로 목표 난이도 4점은 제외한다.

## 2. v1.8.4 적용 차이

v1.8.4에서는 Gate PASS 문항의 선택지 품질을 6점에서 시작해 감점한다.

기존 결과와 달라진 핵심은 Q5이다. Q5는 3점 일반 5지선다인데, 오답들이 모두 독립운동 주제권 안에 있으나 발문 조건 적용 후 실제 비교 후보로는 거의 남지 않는다. 따라서 기존 2점이 아니라 다음처럼 본다.

```text
6점
- 유효 매력 오답 0개: -3
= 3점
```

단, Q5라도 Gate FAIL 문항은 그대로 0점이다.

## 7. 조건별 해석

| 조건 | 해석 |
|---|---|
| gpt-4.1-mini 기본/H1/H2/H3 | Gate 안정성이 낮다. 주요 실패는 G5 오답 역사 사실성, G6 정답 노출·외형 편향, G2/G3 형식·정답 유일성 문제다 |
| gpt-4.1 기본 | 가장 강한 GPT 조건 중 하나다. SLLM이 실패한 Q1을 살리고, Q5도 Gate PASS 후 감점식 3점으로 처리되어 총점이 높다 |
| gpt-4.1 H1 | SLLM과 동률이다. 다만 Q6에서 정답 외형 편향/형식 문제가 발생해 기본 조건보다 떨어졌다 |
| gpt-4.1 H2/H3 | 힌트가 늘면서 일부 문항에서 과설명형 정답 선지와 형식 편향이 생겨 점수가 내려갔다 |
| gpt-5 기본/H1/H2/H3 | 전반적으로 상위권이다. 다만 H2는 Q8에서 정답 선지 외형 편향이 약하게 남아 5점 처리되었다 |
| SLLM v41 | mini급 GPT보다 훨씬 안정적이다. 약점은 Q1처럼 발문 구조 자체가 틀어진 경우를 스스로 우회하지 못한다는 점이다 |

## 8. 결론

v1.8.4 재평가에서도 순위는 크게 바뀌지 않는다.

```text
SLLM v41은 gpt-4.1-mini 계열보다 확실히 안정적이다.
gpt-4.1 기본 및 gpt-5 계열은 SLLM과 동급 이상이다.
SLLM의 장점은 상위 GPT 절대 우위가 아니라, 저비용 7B 모델이 mini급 GPT보다 안정적인 Gate 통과율과 선택지 품질을 보인다는 점이다.
```

발표에서는 아래 문장이 방어 가능하다.

```text
10문항 재평가 기준, SLLM v41은 gpt-4.1-mini 대비 명확히 우세했으며 gpt-4.1 H1과는 동률이었다. 다만 gpt-4.1 기본 및 gpt-5 조건에서는 상위 GPT가 더 높은 점수를 보였다. 따라서 SLLM의 가치는 최고 성능 절대 우위가 아니라 비용 대비 안정성과 경량 배포 가능성에 있다.
```
