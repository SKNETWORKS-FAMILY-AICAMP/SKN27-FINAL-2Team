# v41 SLLM vs 전체 GPT 조건 수동 평가 보고서

## 1. 평가 범위

v41 SLLM 결과를 기준으로 GPT 비교군을 다시 맞췄다. 입력이 바뀐 4번·10번은 모든 GPT 조건에서 새로 생성했고, 기존 조건 결과가 있는 1,2,3,5,6,7,8,9번은 기존 결과를 재사용했다.

추가로 기존에 없던 `gpt-4.1 기본`, `gpt-5 기본`은 v41 첫 10문항 전체를 새로 생성했다.

## 2. 조건 정의

| 조건 | 의미 |
|---|---|
| 기본 | 원래 생성 프롬프트만 제공 |
| H1 | 자기검수 체크리스트 추가 |
| H2 | 자기검수 체크리스트 + 좋은/나쁜 예시 추가 |
| H3 | 자기검수 체크리스트 + 예시 + Gate 요약 추가 |

## 6. 주요 판정 사유

| 문항 | 주요 판단 |
|---:|---|
| 1 | SLLM은 `사이 시기` 발문 때문에 정답 시기 조건이 맞지 않아 G3 FAIL. 상위 GPT는 발문을 `왕의 재위 시기`로 바꿔 문항을 살림 |
| 2 | mini 계열 일부는 오답에서 궁예·태봉·마진의 순서 관계를 틀리게 써 G5 FAIL. gpt-4.1 이상은 대체로 통과 |
| 3 | 지도 자료가 없는데 위치 선택지를 요구하므로 대부분 G2/G3 FAIL. 이 문항은 모델 문제가 아니라 입력 구성 자체의 한계가 큼 |
| 4 | mini 계열은 자료 문장을 거의 복사하거나 오답에 허위 진술을 섞어 FAIL. gpt-4.1 이상은 `영릉가 전투`를 넣어 문항을 살림 |
| 5 | 대부분 Gate는 통과하더라도 3점 문항치고 오답이 너무 앞선 시기라 유효 매력 오답이 부족해 2/6점 |
| 6 | 순서 배열형은 SLLM과 상위 GPT 모두 강함. 단, 일부 GPT 조건은 정답 선지만 장문 해설형으로 튀어 G6 또는 형식 문제로 FAIL |
| 7 | mini 계열은 `왜관-명나라 무역`, `과전법=토지 소유권` 같은 역사 오류를 만들어 FAIL. 상위 GPT는 대체로 통과 |
| 8 | mini 및 일부 4.1 조건은 정답 선지만 장문 설명형이고 오답은 기호 조합이라 G6 외형 편향으로 FAIL. gpt-5는 대체로 안정 |
| 9 | mini 계열은 고조선·백제·신라 제도 설명에서 허위 진술을 섞어 G5 FAIL. 상위 GPT는 대체로 통과 |
| 10 | mini 계열은 정답 노출 또는 역사 오류가 많음. gpt-4.1 이상은 태조 왕건 정책 비교 문항으로 안정화됨 |

## 7. 해석

이번 전체 조건 재평가에서는 `gpt-4.1-mini`는 SLLM v41보다 확실히 낮다. 기본·H1·H2·H3 모두 Gate 안정성이 부족했고, 특히 오답 역사 사실성(G5)과 정답 노출·외형 편향(G6)에서 많이 무너졌다.

반면 `gpt-4.1`과 `gpt-5`는 SLLM v41과 동급 이상으로 올라온다. 특히 `gpt-4.1 기본`, `gpt-5 H1`, `gpt-5 H3`는 SLLM보다 총점이 높다. 가장 큰 이유는 1번 문항이다. SLLM은 1번을 구조적으로 실패했지만, 상위 GPT는 발문을 더 안전하게 바꿔 Gate를 통과했다.

즉 발표용 결론은 이전보다 더 정교하게 말해야 한다.

```text
SLLM v41은 gpt-4.1-mini 계열보다 훨씬 안정적이다.
하지만 gpt-4.1 이상, 특히 gpt-5에 충분한 조건을 주면 SLLM과 동급 또는 그 이상 품질이 나온다.
SLLM의 강점은 mini급 대비 비용·속도·안정성이고, 약점은 특정 발문 구조 실패를 스스로 회피하는 능력이 상위 GPT보다 낮다는 점이다.
```

## 8. 발표용 한 줄

```text
v41 SLLM은 gpt-4.1-mini 대비 압도적으로 안정적이지만, gpt-4.1/gpt-5급 모델은 발문을 더 안전하게 재구성해 일부 조건에서 SLLM을 추월했다. 따라서 SLLM의 가치는 최고 성능 절대 우위가 아니라, 낮은 비용에서 mini급 GPT보다 안정적인 한능검 선지 생성 성능을 보인다는 데 있다.
```
