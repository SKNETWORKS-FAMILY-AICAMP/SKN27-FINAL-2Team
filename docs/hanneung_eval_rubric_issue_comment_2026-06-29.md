# GitHub 이슈 댓글용 요약본 2026-06-29

## 한능검 SLLM 평가표 수정 요약

오늘 평가표와 API 실험 기준을 실제 평가 흐름 기준으로 정리했습니다.

평가 흐름은 아래 순서입니다.

1. Gate 평가
2. 문제 10점 평가
3. 해설 5점 평가
4. 최종 판정
5. 결과표 출력

## 핵심 변경

### 1. Gate FAIL 처리 방식 변경

기존에는 Gate FAIL이면 모두 `regenerate`로 처리했지만, 이제는 실패 Gate에 따라 `repair`와 `regenerate`를 분리합니다.

| 실패 Gate | 처리 |
|---|---|
| G1/G2/G5/G6만 실패 | `repair` |
| G3 또는 G4 포함 | `regenerate` |
| uncertain | `needs_verification` |

의도는 문항을 무조건 버리지 않고, 선지 교체나 발문 수정으로 살릴 수 있는 문항은 `repair` 큐로 보내는 것입니다.

### 2. G5 오답 역사 사실성 기준 강화

G5는 오답 선지 자체가 역사적으로 성립하는지 판단합니다.

정상 오답과 역사 오류 오답을 분리했습니다.

- 다른 인물·단체·시대의 실제 역사 사실이면 정상 오답
- 발문 주체에 대입했을 때만 틀리는 것은 G5 FAIL 아님
- 실제로 없는 계승·해체·인과·순서 관계를 만들면 G5 FAIL
- 시기상 존재할 수 없는 주체가 사건을 지원·탄압·주도했다고 하면 G5 FAIL

예시:

| 선지 | 판정 |
|---|---|
| `2·8 독립 선언서를 발표하였다` | 일본 유학생의 실제 사실이므로 정상 오답 |
| `봉오동 전투에서 일본군을 격파하였다` | 대한 독립군 등의 실제 사실이므로 정상 오답 |
| `한인 애국단으로 발전적으로 해체되었다` | 실제 관계가 아니므로 G5 FAIL |
| `신간회의 지원을 받아 전개되었다` | 시기상 성립하지 않아 G5 FAIL |
| `원산 총파업으로 이어졌다` | 직접 인과·연결 관계가 성립하지 않으면 G5 FAIL |

### 3. G6 정답 노출 기준 정리

G6는 쉬운 문제를 모두 탈락시키는 기준이 아니라, 정답 선지만 발문·자료 표현을 거의 그대로 반복해 문장 매칭으로 정답을 고를 수 있는 경우를 잡는 Gate입니다.

G6 하위 기준:

- G6-1: 정답명·핵심명 직접 노출
- G6-2: 정답 선지 진술 복사·의역
- G6-3: 정답 외형 편향

38번처럼 애매한 경우도 확인했습니다. 현재는 보수적으로 G6 FAIL 처리하고 `repair`로 보냅니다.

### 4. 문제 10점 평가 단위 압축

Gate PASS 문항만 문제 10점을 채점합니다.

| 항목 | 배점 |
|---|---:|
| 목표 난이도 적합성 | 4점 |
| 선택지 품질 | 6점 |

선택지 품질은 응답 범주 적합성, 중복·포함 관계, 유효 매력 오답 수를 봅니다.

### 5. 해설 5점 평가 유지

해설 평가는 기존 5개 항목을 유지합니다.

| 항목 | 배점 |
|---|---:|
| 정답 근거 제시 | 1점 |
| 단서 사용 설명 | 1점 |
| 오답 배제 설명 | 1점 |
| 정답-해설 일치 | 1점 |
| 해설 사실성 | 1점 |

Gate FAIL이면 문제 점수와 해설 점수는 모두 null로 둡니다.
