# 한능검 SLLM 문항 평가지표 v1.8.6

## 1. 목적

이 문서는 한국사능력검정시험 심화형 5지선다 문항을 LLM judge 또는 사람 검수자가 평가하기 위한 순수 문항 품질 기준이다.

현재 기준은 Evidence Pack, target_period, target_topic, target_major_type, target_minor_type을 평가하지 않는다. 문항 자체의 성립 여부와 품질만 평가한다.

## 2. v1.8.6 변경 요약

- 2점도 3점과 같이 단서 수와 매력 오답 수를 일괄 강제하지 않고, 표준 수준의 주된 난이도 기제가 실제로 작동하는지 평가한다.
- 2점은 대표 추론, 식별 후 표준 사실 비교, 넓은 시기·전후 판단, 중간 수준의 가까운 선지 비교 중 하나가 작동하면 성립할 수 있다.
- 대상명 직접 노출만으로 2점 난이도 상한을 고정하지 않으며, 별도 사실 비교가 남는지로 판단한다.

- 최근 5회차 실제 3점 문항 50개 분석을 반영해, 3점 난이도를 단서 수·매력 오답 수의 동시 충족으로 제한하지 않는다.
- 사료·우회 단서 해석, 정밀한 연대·관계 판단, 세부 지식, 가까운 선지 비교 중 하나가 주된 난이도로 작동하면 3점으로 인정할 수 있다.
- 가까운 오답 수는 가까운 선지 비교가 주된 난이도 기제인 문항에서만 3점 판정의 핵심 근거로 사용한다.

- Gate 항목을 11개에서 6개 묶음으로 압축했다.
- 기존 G11 직접 대응을 `G6-1 정답명 직접 노출`, `G6-2 정답 선지 진술 복사`, `G6-3 대상명 직접 노출`, `G6-4 정답 외형 편향`으로 나누었다.
- 문제 평가표를 `목표 난이도 적합성 4점`, `선택지 품질 6점`의 2개 항목으로 압축했다.
- Gate와 평가표의 중복을 줄였다. 직접 노출·문장 복사·심한 정답 외형 편향은 Gate에서 처리하고, 평가표는 Gate 통과 후 난이도와 오답 품질을 중심으로 평가한다.
- G3에서 `선지 자체의 역사 사실성`과 `선지가 발문·자료 조건을 역사적으로 충족하는지`를 분리해 검증하도록 강화했다.
- LLM judge가 Gate를 성급히 PASS 처리하지 않도록 `사전 탈락 위험 스캔`, `선택지 명제 분해`, `G6 의미 동일성 검증`, `Gate 자기일관성 점검`을 추가했다.
- 코드 검증은 역사 키워드 하드코딩이 아니라, 형식 오류, 정답 선지의 발문 표현 반복, 구조화 결과와 Gate 판정의 자기모순만 검사한다.
- Gate PASS 이후 감점 편차를 줄이기 위해 목표 난이도와 선택지 품질의 고정 감점표를 추가했다.
- 선택지 품질 6점을 Gate PASS 후 감점식으로 명확히 바꾸었다.
- 일반 5지선다와 조합형·순서형을 분리했다. 일반 5지선다는 유효 매력 오답 수를 보고, 조합형·순서형은 보기·사건 간 시대·주제·전개 과정 근접성을 본다.

## 3. 운영 원칙

- 한 번에 문항 1개만 평가한다.
- 여러 문항이 입력되면 가장 앞 번호 1개만 평가하고, 나머지는 평가하지 않는다.
- 입력된 question_id 외의 문항을 언급하거나 비교하지 않는다.
- Gate는 점수보다 우선한다.
- Gate 하나라도 FAIL이면 점수 채점을 중단하고, 실패 Gate에 따라 repair 또는 regenerate로 처리한다.
- Gate uncertain은 PASS가 아니다. 후속 검증이 필요하면 needs_verification으로 처리한다.
- Gate 통과 후에만 문제 10점을 채점한다.
- 문항 형식이 그럴듯하다는 이유로 내용 검증을 생략하지 않는다.
- 역사 사실성은 LLM의 일반 한국사 지식 기준으로 판단하되, 세부 고증이 애매하면 uncertain으로 남긴다.
- 코드 기반 보조 검증은 특정 역사 사건·인물·시대 키워드를 정답/오답으로 하드코딩하지 않는다.
- 코드 기반 보조 검증은 선택지 개수·정답 대응·빈 값 같은 형식 검증, 발문과 정답 선지의 일반 문자열 반복, LLM 구조화 결과와 Gate 판정의 논리 모순만 처리한다.

## 4. 복수 문항 입력 처리

| 상황 | 처리 |
|---|---|
| 문항 1개 입력 | 해당 문항만 평가 |
| 문항 여러 개 입력 | 가장 앞 번호 1개만 평가 |
| "41~50번 평가"처럼 범위 입력 | 41번만 평가하고 다음 문항 진행 대기 |
| 응답 중 다른 문항 언급 | 평가 오류로 간주 |

## 5. uncertain 처리 규칙

| 상태 | 처리 |
|---|---|
| 명백한 오류 | Gate FAIL |
| 역사 사실성 uncertain, 정답 유일성에 영향 없음 | Gate 보류, 후속 검증 필요 |
| 역사 사실성 uncertain, 정답 유일성에 영향 있음 | G3 정답 성립성 위험으로 regenerate 권장 |
| 외부 검증 후 사실로 확인 | PASS |
| 외부 검증 후 오류로 확인 | Gate FAIL |
| 외부 검증 불가 | 점수 채점 보류, needs_verification |

## 6. Gate v1.8.6

Gate는 문항 성립 조건이다. 하나라도 FAIL이면 점수 평가를 진행하지 않는다. 단, 모든 Gate FAIL이 G1/G2/G5/G6에 속하면 부분 수정 가능한 문항으로 보아 repair로 처리할 수 있고, G3/G4가 포함되면 문항 구조나 발문·자료 고증이 흔들린 것이므로 regenerate를 우선한다.

| Gate | 항목 | FAIL 기준 |
|---|---|---|
| G1 | 입력·형식 성립 | 발문, 선택지, 정답, target_score 중 하나라도 없거나, 선택지가 정확히 5개가 아니거나, 정답이 ①~⑤ 또는 1~5 중 정확히 하나가 아니거나, target_score가 1점·2점·3점 중 하나가 아님 |
| G2 | 발문·선지 판독 가능성 | 문장 파손·누락으로 의미 판단이 불가능하거나, 뜻을 추정할 수 있더라도 주어·서술어 호응, 조사·목적어 결합, 동사와 대상의 의미 관계가 객관적으로 깨져 한능검 선지 문장으로 사용할 수 없거나, 발문이 요구하는 응답 형식과 선택지 형식이 맞지 않음 |
| G3 | 정답 성립성 및 발문 조건 충족 유일성 | 발문·자료 조건을 역사적으로 만족하는 선택지가 0개 또는 2개 이상이거나, 표시 정답이 발문 조건 또는 한국사 사실과 명백히 충돌함. 선택지 자체는 사실이어도 발문 조건을 만족하면 정답 후보로 반드시 센다 |
| G4 | 발문·자료 사실성 및 내부 일관성 | 발문·자료의 핵심 단서가 역사 사실과 명백히 충돌하거나, 자료 내부 인물·시기·사건·저작·발화 주체가 명백히 모순됨 |
| G5 | 오답 역사 사실성 | 오답 4개 중 하나라도 한국사 세계 안에서 성립하지 않는 가짜 용어·가짜 사건·허위 결합이면 FAIL. 정답 대상에 대입했을 때 틀린다는 이유만으로 FAIL하지 않으며, 다른 실제 역사 대상의 사실 설명으로 성립하면 PASS. 세부 사실 확인이 애매하면 FAIL이 아니라 Gate uncertain으로 기록 |
| G6 | 정답 노출·복사·외형 편향 | G6-1, G6-2, G6-3, G6-4 중 Gate FAIL 조건에 해당하여 역사 지식 없이 정답을 추정하거나 확정 가능 |

G2는 선택지 5개를 각각 검사한다. 역사 사실을 복원해 이해할 수 있다는 이유로 비문을 PASS시키지 않으며, 잘못된 조사·목적어·수식 관계를 fact_basis에 맞춰 마음속으로 보정하거나 생략된 말을 임의로 보충해 읽지 않는다. 선지 원문 그대로는 성립하지 않고 고쳐 읽어야만 성립하면 G2 FAIL이다. 다만 더 자연스러운 대안이 있다는 정도의 문체 취향은 FAIL 사유가 아니다. 정답 선지의 G2 오류는 `correct`, 오답 선지의 오류는 해당 `choice:①`~`choice:⑤`를 repair target으로 지정하고, fact_basis의 주체·행위·대상 관계를 보존한 자연스러운 문장으로 고치도록 지시한다.

## 7. G5 오답 역사 사실성 세부 규칙

| 오답 유형 | 판정 |
|---|---|
| 역사적으로는 맞지만 발문 조건과 맞지 않음 | PASS |
| 다른 시대·인물·제도에 대한 역사적으로 맞는 사실 | PASS. 발문 주어를 대입하면 오답이 되더라도, 선지 내용 자체가 다른 역사 주체의 실제 정책·사건으로 성립하면 정상 오답으로 본다 |
| 서로 다른 역사 사실을 한 주체의 활동처럼 잘못 결합 | FAIL |
| 사건 순서, 주체, 시기, 결과를 명백히 잘못 연결 | FAIL |
| 실제 역사에서 성립하지 않는 가짜 용어·가짜 사건·가짜 제도 | FAIL |
| 실제 역사 맥락은 있으나 어느 대상의 설명인지 안정적으로 특정하기 어려움 | Gate uncertain 또는 repair warning. 명백한 허위 결합이 아니면 G5 FAIL로 확정하지 않는다 |
| 세부 사실 확인이 애매함 | Gate uncertain, 후속 검증 필요 |

G5에서는 선택지 원문을 더 안전한 참 문장으로 바꿔 평가하면 안 된다. 선택지 원문이 주장하는 핵심 술어, 관계, 결과를 그대로 보존한 뒤 그 전체 명제가 역사적으로 성립하는지 판단한다. 예를 들어 어떤 오답이 `A로 발전`, `A로 해체`, `A로 이어짐`, `A를 계승`, `A와 통합` 같은 관계를 주장하면, 단순히 A가 실제로 존재하는지만 보지 말고 그 관계 자체가 실제로 성립하는지 검증한다.

단, 주체 식별형 문항에서 주어가 생략된 오답을 평가할 때 발문 정답 주체를 `historical_proposition`에 억지로 넣으면 안 된다. 먼저 그 선지의 행위·사건을 실제로 수행한 역사 주체를 복원한다. 같은 서술이 다른 실제 주체의 사실로 성립하면 `valid_other_fact`, `satisfies_stem_condition=no`인 정상 오답이다. 발문 주체에 대입했을 때 틀린다는 이유만으로 G5 FAIL을 주지 않는다. 실제 주체가 확실하지 않지만 역사적 계열·맥락이 일부 존재하면 `uncertain`으로 두고, 명백한 가짜 용어·허위 결합일 때만 FAIL한다.

예를 들어 발문 주체 X를 묻는 문항에서 오답이 `B 선언서를 발표하였다`이면 `historical_proposition`은 `실제 발표 주체가 B 선언서를 발표하였다`가 되어야 한다. `X가 B 선언서를 발표하였다`라고 쓰면 안 된다. 오답이 `Y 전투에서 적군을 격파하였다`이면 `실제 전투 주체가 Y 전투에서 적군을 격파하였다`로 검증한다. 반대로 `A 단체로 발전적으로 해체되었다`처럼 전환·계승 관계를 말하는데 그 관계를 실제로 가진 역사 주체가 없으면 `fabricated_relation` 또는 `false_causality`로 본다.

G5 적용 예시는 다음과 같다.

| 오답 선지 | 판정 |
|---|---|
| 이순신 문항에서 `칠천량 해전에서 전사하였다` | PASS. 이순신 설명은 아니지만 실제 역사 맥락 안에서 성립하는 오답이다 |
| 이순신 문항에서 `행주대첩을 지휘하였다` | PASS. 권율의 활동으로 성립하므로 발문 조건 불충족 오답이다 |
| 이순신 문항에서 `전장에서 평평선을 타고 싸웠다` | G5 FAIL. 한국사 안에서 성립하지 않는 가짜 용어·가짜 사실이다 |
| 이순신 문항에서 `자라선을 운용한 것으로 유명하다` | G5 FAIL. 한국사 안에서 성립하지 않는 가짜 용어·가짜 사실이다 |
| 흥선 대원군 문항에서 `탕평비를 세워 붕당 정치의 폐해를 경계하였다` | PASS. 영조의 정책으로 역사적으로 성립하므로 발문 조건 불충족 오답이다 |
| 흥선 대원군 문항에서 `전국에 척화비를 세운 뒤 갑신정변을 일으켰다` | G5 FAIL. 척화비 건립과 갑신정변을 한 주체의 연속 행위처럼 허위 결합하였다 |
| 광개토 대왕 문항에서 `만주를 정복하여 척화비를 세웠다` | G5 FAIL. 광개토 대왕 계열 사실과 흥선 대원군 계열 사실을 인과 관계처럼 섞었다 |
| 세종 문항에서 `훈민정음을 반포하기 위해 태학을 설립하였다` | G5 FAIL. 훈민정음 반포와 고구려 태학 설립을 목적 관계로 허위 결합하였다 |
| 한국 독립군 문항에서 `조선 의용대로부터 분리되어 결성되었다` | 바로 G5 FAIL로 확정하지 않는다. 조선의용대 화북지대·조선의용군 등 실제 계열 맥락과 혼동 가능성이 있으면 `uncertain` 또는 repair warning으로 처리한다 |

## 8. G6 정답 노출·복사 세부 규칙

G6은 쉬운 단서를 무조건 탈락시키는 Gate가 아니다. 그러나 정답명 직접 노출이 없더라도, 발문·자료와 정답 선지가 같은 역사 명제를 반복하면 Gate FAIL이다. G6 판단에서는 "정답 고유명사가 그대로 나왔는가"보다 "발문·자료 일부와 정답 선지를 문장 매칭으로 연결할 수 있는가"를 우선한다.

| 하위 Gate | 항목 | 판정 기준 |
|---|---|---|
| G6-1 | 정답명·핵심명 직접 노출 | 발문·자료에 정답 선지의 핵심 고유명사, 사건명, 작품명, 제도명, 기관명, 별칭이 그대로 제시되어 그 단어를 찾는 것만으로 정답 확정 가능 |
| G6-2 | 정답 선지 진술 복사·의역 | 발문·자료의 핵심 기능, 결과, 활동, 생활 모습, 제도 운영, 동사-목적어 표현이 정답 선지에 그대로 또는 거의 같은 의미로 반복되어 문장 매칭만으로 정답 확정 가능 |
| G6-3 | 대상명 직접 노출 | 발문·자료명에 정답 대상명은 드러나지만 정답 선지가 별도 업적·정책·결과를 요구하면 Gate PASS 후 난이도 감점. 대상명만 보고 정답 선지까지 바로 확정 가능하면 G6 FAIL |
| G6-4 | 정답 외형 편향 | 정답 선지만 길이, 구체성, 발문 표현 반복, 문장 형식에서 두드러져 역사 지식 없이 정답을 추정 가능 |

정답 선지의 핵심 표현에는 아래가 포함된다.

| 유형 | 예시 |
|---|---|
| 고유명사 | 아리랑, 신민회, 사헌부 |
| 사건명 | 갑신정변, 병인양요 |
| 제도명·기관명 | 정방, 사헌부, 통리기무아문 |
| 별칭 | 홍의 장군 |
| 핵심 기능 표현 | 관리의 비리를 감찰하였다 |
| 핵심 결과 표현 | 인사권을 장악하였다 |
| 핵심 활동 표현 | 의령에서 의병을 이끌었다 |

| 경우 | 판정 |
|---|---|
| 발문에 "나운규, 1926년, 영화"가 있고 정답이 "아리랑" | Gate PASS, 난이도 감점 가능 |
| 발문에 "아리랑"이 있고 정답이 "아리랑" | G6-1 FAIL |
| 자료명에 "진흥왕 순수비"가 있고 정답이 진흥왕의 별도 업적임 | G6-3 Gate PASS, 별도 업적 비교가 실제로 필요하면 target_score 2점 적합 가능 |
| 자료명에 "진흥왕 순수비"가 있고 정답이 "진흥왕" 자체임 | G6-1 또는 G6-3 FAIL |
| 발문에 정답명은 없지만 정답 선지의 핵심 생활 모습, 제도 운영, 업적 표현이 같은 뜻으로 반복됨 | G6-2 FAIL |
| 발문 표현과 정답 선지의 동사·목적어가 거의 같음 | G6-2 FAIL |
| 발문의 기능·결과·활동 표현이 정답 선지에 그대로 반복됨 | G6-2 FAIL |
| 정답 선지가 새로운 수단·방법을 덧붙였더라도 발문에 이미 제시된 핵심 활동·결과를 유일하게 재진술함 | G6-2 FAIL |
| 발문은 강한 단서만 주고 정답 선지가 별도 지식으로 연결됨 | Gate PASS, 난이도에서 판단 |
| 자료 해석형에서 정답 선지가 자료 문장을 단순 반복함 | G6-2 FAIL |
| 자료 해석형에서 정답 선지가 자료 내용에서 한 단계 추론된 역사적 의미를 제시함 | PASS |
| 자료 표현이 선택지 5개에 같은 방식으로 반영되어 있고, 정답 선지만 튀지 않음 | Gate PASS 가능, 난이도에서 판단 |
| 정답 선지만 자료 표현을 거의 그대로 가져옴 | G6-2 FAIL |

G6-3 대상명 직접 노출은 쉬운 문항을 무조건 Gate FAIL로 만들기 위한 기준이 아니다. 자료명이나 발문에 왕·인물·단체·국가·시대명이 직접 보이더라도, 선택지에서 별도 업적·정책·결과를 골라야 하면 Gate는 PASS로 둔다. target_score 1·2점은 해당 배점 기준으로 판단하고, target_score 3점은 대상 식별 뒤 세부 지식·연대·관계 판단이 실제로 남는지 확인한다.

G6-4는 아래 편향 신호 중 2개 이상이 정답 선지에만 나타나면 FAIL로 본다.

| 편향 신호 | G6-4 판정 기준 |
|---|---|
| 길이 편향 | 정답 선지만 오답 평균보다 50% 이상 길거나 짧고, 차이가 12글자 이상임 |
| 구체성 편향 | 정답 선지만 연도·인명·지명·기관명·사건명 등 구체 정보가 오답 평균보다 3개 이상 많음 |
| 발문 표현 반복 | 정답 선지만 발문 핵심어 또는 핵심 구를 2개 이상 반복함. G6-2 수준의 명제 반복이면 G6-2로 처리 |
| 문장 형식 편향 | 정답 선지만 부정형, 예외형, 과도한 원인-결과형, 긴 수식어 구조 등 나머지 4개와 다른 문장 형식임 |

G6-2는 아래처럼 표현이 달라도 같은 역사 명제이면 FAIL로 본다.

| 발문·자료 표현 | 정답 선지 표현 | 판정 |
|---|---|---|
| 막집을 짓고 살며 사냥과 채집으로 식량을 마련 | 동굴이나 막집에서 이동 생활 | G6-2 FAIL 가능. 정답 선지가 발문 속 생활 모습을 거의 그대로 재진술함 |
| 여러 가가 별도의 행정 구역인 사출도를 다스림 | 여러 가들이 별도로 사출도를 다스림 | G6-2 FAIL |
| 태학을 세워 인재를 기름 | 태학을 설립하여 인재를 양성함 | G6-2 FAIL |
| 후당, 오월과 외교 관계를 맺음 | 후당과 오월에 사신을 보내 외교 관계를 맺음 | G6-2 FAIL |
| 서북 지역에 대한 차별과 세도 정치 수탈에 항거 | 서북민에 대한 차별에 반발하여 일어남 | G6-2 FAIL. `서북 지역/서북민`, `항거/반발`처럼 표현만 바뀐 같은 역사 명제이다 |
| 독립운동 자금을 모음 | 독립 공채를 발행하여 자금을 마련함 | G6-2 FAIL 가능. `독립 공채 발행`이라는 수단은 새 정보지만, 정답 선지만 발문의 핵심 활동인 자금 모집·마련을 유일하게 재진술하면 문장 매칭으로 정답 추정이 가능하다 |

반대로 아래 경우는 G6가 아니라 난이도에서 판단한다.

| 발문·자료 표현 | 정답 선지 표현 | 판정 |
|---|---|---|
| 나운규, 1926년, 영화 | 아리랑 | 정답명 직접 노출은 아니므로 Gate PASS. 다만 target_score보다 쉬우면 난이도 감점 |
| 역분전 지급, 기인 제도, 혼인 정책 | 흑창 설치 | 정답 선지 진술 복사는 아니므로 현 G6 기준에서는 Gate PASS. 다만 발문 단서가 target_score보다 강하면 난이도 구조 또는 단서 난도에서 감점 |

## 9. Gate 적용 절차

LLM judge는 Gate 판정 전에 아래 절차를 먼저 수행한다.

| 단계 | 작업 |
|---|---|
| 1 | 입력된 question_id의 문항 1개만 평가 대상인지 확인 |
| 2 | 발문이 요구하는 조건을 한 문장으로 추출 |
| 3 | 자료·대화·제시문 속 핵심 역사 사실을 문장 단위로 추출 |
| 4 | 정답 선지의 핵심 표현을 고유명사, 사건명, 제도명, 별칭, 기능, 결과, 활동으로 나누어 추출 |
| 5 | 선택지 5개 각각의 역사 명제를 추출 |
| 6 | 선택지별로 역사적으로 성립하는가와 발문 조건에 부합하는가를 분리 판단 |
| 7 | 선택지 문장을 주체, 행위, 대상, 시기, 결과, 인과·순서 관계로 분해하고, 부분 사실이 아니라 문장 전체가 역사 명제로 성립하는지 판단 |
| 8 | 발문·자료와 정답 선지의 핵심 표현이 G6-1, G6-2, G6-3, G6-4에 해당하는지 검사. 이때 정답명이 직접 나오지 않았다는 이유만으로 G6를 PASS 처리하지 않는다 |
| 9 | 자료 내부의 인물, 시기, 사건, 저작, 발화 주체가 서로 모순되는지 검사 |
| 10 | 이 문항을 탈락시킬 수 있는 가장 강한 이유를 최대 3개 찾고 Gate를 재검토 |

## 10. 구조화 검증 양식

LLM judge는 Gate를 바로 판정하지 말고 아래 구조화 검증을 먼저 작성한다. 이 검증은 코드 하드체크가 아니라, LLM이 자기 판단을 빠뜨리지 않도록 강제하는 출력 구조이다.

### 10.1 사전 탈락 위험 스캔

| 항목 | 작성 내용 |
|---|---|
| gate | G3, G4, G5, G6 중 의심되는 Gate |
| risk | 가장 의심되는 탈락 가능성 |
| evidence | 발문·자료·선택지의 구체 표현 |
| if_true_consequence | 사실이면 FAIL인지, uncertain인지, 점수 감점인지 |

최소 1개, 최대 3개를 작성한다. 탈락 위험이 없어 보이면 `위험 없음`이라고 쓰되, G5와 G6은 반드시 한 번 검토한다.

### 10.2 선택지 명제 분해

G3, G5 판단 전에 선택지 5개를 모두 아래 형식으로 분해한다.

| 필드 | 의미 |
|---|---|
| choice | 선택지 번호 |
| original_choice_text | 입력 선택지 원문 |
| historical_proposition | 선택지를 하나의 역사 명제로 환원한 문장 |
| subject | 주체 |
| action | 행위 |
| object | 대상 |
| time | 시기 |
| result | 결과 |
| causal_or_sequence_relation | 인과·순서 관계 |
| whole_claim_validity | 문장 전체가 역사 명제로 성립하는지 yes/no/uncertain |
| g5_error_classification | 정상 오답인지, 없는 사실로 만든 오답인지 분류 |
| true_parts | 부분적으로 맞는 사실 |
| false_or_unsupported_parts | 틀리거나 결합이 불가능한 부분 |
| satisfies_stem_condition | 발문 조건에 부합하는지 yes/no/uncertain |

판정 원칙은 다음과 같다.

- 부분 사실이 각각 실제로 존재해도, 한 주체·한 사건의 활동처럼 결합한 전체 문장이 명백히 틀리면 `g5_error_classification.should_fail_g5=true`이다.
- 다른 인물·시대의 실제 정책이나 사건으로 문장 전체가 성립하면 `g5_error_classification.type=valid_other_fact`이고, 발문 조건 불충족 오답으로 처리한다.
- 오답이 정답 대상에 대한 설명으로 틀린 것과, 오답 문장 자체가 한국사 안에서 성립하지 않는 것은 구분한다. 전자는 정상 오답이고 후자만 G5 FAIL이다.
- `original_choice_text`에는 입력 선택지를 그대로 적는다.
- G5의 `historical_proposition`과 `whole_claim_validity`는 선택지 문장 자체를 기준으로 작성한다. 선택지에 명시되지 않은 발문 주어를 임의로 대입하지 않는다.
- `historical_proposition`은 `original_choice_text`의 핵심 술어, 관계, 결과를 누락하면 안 된다. 원문이 `해체되었다`, `이어졌다`, `계승하였다`, `통합되었다`, `원인이 되었다`처럼 관계를 말하면 그 관계 표현을 보존해 검증한다.
- 발문 주어·조건과 맞는지는 `satisfies_stem_condition`에서 별도로 판단한다.
- 주체가 생략된 오답은 실제 역사 주체를 먼저 복원한다. 실제 주체를 알 수 없지만 역사적 계열·맥락이 일부 있으면 `uncertain`으로 두며, 발문 주체를 임의 대입해 G5 FAIL을 만들지 않는다.
- `whole_claim_validity=no`만으로 G5 FAIL을 확정하지 않는다. G5 FAIL은 `g5_error_classification.should_fail_g5=true`일 때 확정한다.
- `g5_error_classification.type`은 `valid_other_fact`, `fabricated_relation`, `nonexistent_term_or_fact`, `mixed_fact_hybrid`, `false_actor_action`, `false_time`, `false_causality`, `false_sequence`, `false_result`, `uncertain` 중 하나로 쓴다.
- `g5_error_classification.type`이 `nonexistent_term_or_fact`, `mixed_fact_hybrid`, `fabricated_relation`, `false_causality`, `false_sequence`, `false_result` 중 하나이고 다른 실제 역사 대상의 사실 설명으로 성립하지 않으면 `should_fail_g5=true`여야 한다.
- `false_actor_action`, `false_time`은 신중하게 쓴다. 같은 문장이 다른 실제 역사 대상의 사실로 성립하면 `valid_other_fact`이고, 실제 대상이 불명확하지만 역사적 맥락이 일부 있으면 `uncertain`이다. 명백히 가짜 용어·가짜 사건이거나 서로 다른 사실을 한 주체의 활동처럼 섞은 경우에만 G5 FAIL이다.

### 10.3 G6 의미 동일성 검증

G6 판단 전에 발문·자료의 핵심 명제와 정답 선지의 핵심 명제를 각각 일반화된 한 문장으로 환원한다.

| 필드 | 의미 |
|---|---|
| stem_core_claims | 발문·자료의 핵심 명제 목록 |
| correct_choice_claim | 정답 선지의 핵심 명제 |
| shared_meaning_units | 단어가 달라도 같은 의미로 작동하는 단위 |
| relation | none, weak_keyword, target_name_exposure, partial_same_claim, same_core_claim, direct_copy, external_bias 중 하나 |
| can_answer_by_text_matching_without_history | 역사 지식 없이 문장 매칭만으로 정답을 고를 수 있는지 |
| g6_should_fail | G6 FAIL이어야 하는지 |

판정 원칙은 다음과 같다.

- 단어가 완전히 같지 않아도 `주체 범주`, `행위 의미`, `원인`, `결과`가 같은 명제이면 G6-2를 검토한다.
- `target_name_exposure`는 G6-3으로 보고, 대상명 노출만으로 정답 선지를 확정할 수 없으면 Gate PASS 후 난이도 감점으로 처리한다.
- `same_core_claim`, `direct_copy`, `external_bias`이면 G6 FAIL이다.
- `partial_same_claim`이라도 정답 선지만 그 표현을 받아 정답을 사실상 확정할 수 있으면 G6 FAIL이다.
- `weak_keyword`는 공통 키워드만 있고 문장 매칭으로 정답 확정이 어려운 경우에만 사용한다.

### 10.4 Gate 자기일관성 점검

Gate 최종 판정 전 아래 항목을 확인한다.

| 조건 | 일관된 Gate 판정 |
|---|---|
| 발문 조건에 부합하는 선택지 수가 0개 또는 2개 이상 | G3 FAIL |
| 오답 중 `g5_error_classification.should_fail_g5=true`가 1개 이상 | G5 FAIL |
| `g6_should_fail=true` | G6 FAIL |
| 자료 내부 인물·시기·사건·저작·발화 주체가 명백히 모순 | G4 FAIL |

구조화 검증 결과와 Gate 표가 충돌하면 `gate_consistency_check.consistency_violations`에 충돌 내용을 쓰고, Gate 판정을 구조화 검증에 맞게 수정한다.

`gate_consistency_check`에는 아래 필드를 사용한다.

| 필드 | 의미 |
|---|---|
| g5_fail_choices | `g5_error_classification.should_fail_g5=true`인 오답 번호 목록 |
| satisfying_choice_count_from_choice_verification | 발문 조건 충족 선택지 수 |
| g6_equivalence_requires_fail | G6 의미 동일성 검증상 FAIL이 필요한지 |
| consistency_violations | 구조화 결과와 Gate 판정 충돌 목록 |

## 11. 선택지-발문 역사 관계 검증 양식

G3, G5 판단 전에 선택지별로 아래 정보를 작성한다. 이 단계의 목적은 `선지 문장 자체가 역사적으로 맞는가`와 `그 선지가 발문·자료 조건을 역사적으로 만족하는가`를 분리하는 것이다. G3 판단에서는 `가장 적절한 것`이라는 표현으로 복수 후보를 덮지 않는다. 발문 조건을 문자 그대로 적용했을 때 역사적으로 성립하는 선지가 2개 이상이면 G3 FAIL이다.

발문 조건은 아래 순서로 추출한다.

| 단계 | 작업 |
|---|---|
| 1 | 발문이 요구하는 명시 조건을 모두 추출한다 |
| 2 | 자료·표·연표·대화 속에서 정답 후보가 만족해야 하는 시기, 주제, 범주 조건을 추출한다 |
| 3 | 선택지 5개를 각각 명시 조건과 자료 조건에 대조한다. 이때 선택지가 역사적으로 사실이면, 그 사실의 시대·주제·주체가 발문 조건 범위 안에 들어오는지 별도로 판단한다 |
| 4 | 조건을 만족하는 선택지가 2개 이상이면 `더 대표적`, `더 중요`, `가장 부합`, `완전 부합하지 않음`이라는 이유로 PASS 처리하지 않고 G3 FAIL로 처리한다 |

G3에서는 발문·자료에 없는 숨은 배제 조건을 만들면 안 된다. 예를 들어 발문이 단순히 `고려 시대 화폐사`를 요구하는데, 평가자가 임의로 `고려가 자체 주조한 화폐만 허용`, `가장 대표적인 화폐만 허용`, `유통 부진을 포함해야 함` 같은 조건을 추가하면 안 된다. 이런 제한이 발문·자료에 명시되어 있지 않다면, 같은 시대·같은 주제에 속하는 역사적으로 성립하는 선지는 발문 조건 충족 후보로 센다.

G3에서는 특정 용어가 교과서에서 어느 나라·시대의 대표 키워드로 외워지는지만 보고 오답 처리하면 안 된다. 선택지 원문 전체를 일반 역사 명제로 바꾼 뒤, 그 명제가 발문 대상에도 역사적으로 성립할 수 있으면 정답 후보로 센다. 대표 암기어가 다른 대상을 가리키더라도, 선지 문장의 의미가 발문 대상의 구조·제도·풍습과 겹치면 복수 정답 위험으로 본다.

특히 연표·구성안·시대 흐름형 문항에서는 빈칸 위치가 만드는 넓은 시기 조건을 임의로 좁히면 안 된다. 예를 들어 `통일 신라` 다음, `조선 후기` 앞의 빈칸은 기본적으로 고려 시기를 가리킨다. 이때 선택지 ④가 `고려 전기 자체 화폐 주조`, 선택지 ⑤가 `고려 후기 원 화폐 유입·사용`처럼 둘 다 고려 화폐사로 성립한다면, 발문에 `자체 주조`, `유통 부진`, `고려 전기` 같은 제한이 없는 한 둘 다 발문 조건 충족 후보로 센다.

| 선택지 | 역사 명제 | 역사적으로 성립? | 발문 조건에 부합? |
|---|---|---|---|
| ① | 선택지 내용을 역사 명제로 환원 | yes/no/uncertain | yes/no/uncertain |
| ② | 선택지 내용을 역사 명제로 환원 | yes/no/uncertain | yes/no/uncertain |
| ③ | 선택지 내용을 역사 명제로 환원 | yes/no/uncertain | yes/no/uncertain |
| ④ | 선택지 내용을 역사 명제로 환원 | yes/no/uncertain | yes/no/uncertain |
| ⑤ | 선택지 내용을 역사 명제로 환원 | yes/no/uncertain | yes/no/uncertain |

판정 규칙은 다음과 같다.

- 역사적으로 성립하지만 발문 조건에 맞지 않음: 정상 오답
- 역사적으로 성립하지 않음: G5 FAIL
- 발문 조건에 부합하는 선지가 2개 이상: G3 FAIL
- 불확실한 선택지가 정답 가능성을 흔듦: G3 위험으로 regenerate 권장

G3 적용 예시는 다음과 같다.

| 상황 | 판정 |
|---|---|
| 발문이 `통일 신라와 조선 후기 사이 시기의 화폐사`를 묻고, 선택지 ④와 ⑤가 모두 고려 화폐사로 역사적으로 성립함 | G3 FAIL. 발문 조건을 만족하는 후보가 2개 이상임. ⑤가 덜 대표적이라는 이유만으로 배제할 수 없음 |
| 발문이 `고려의 자체 화폐 주조와 유통 부진`을 명시하고, ④만 이에 해당하며 ⑤는 원 화폐 유입·사용임 | G3 PASS 가능 |
| 선지 하나가 더 대표적이지만 다른 선지도 발문 조건을 만족함 | G3 FAIL. 대표성 차이는 정답 유일성을 만들지 못함 |
| 발문이 `마가·우가·저가·구가`, `사출도`, `영고`로 부여를 가리키고, 선택지에 `여러 가들이 제가 회의를 통해 국가의 중대사를 결정하였다`와 `순장의 풍습이 있었다`가 함께 있음 | G3 FAIL. `제가 회의`는 고구려 대표 용어지만, 선지 전체 의미가 부여의 여러 가 지배 구조와 겹쳐 정답 후보가 2개가 될 수 있음 |

## 12. 문제 평가표 10점

Gate 통과 후 평가한다. 문제 품질은 2개 항목, 총 10점이다. 정답 직접 노출, 정답 선지 복사, 심한 정답 외형 편향, 선택지 형식 붕괴는 점수 감점이 아니라 Gate에서 처리한다.

LLM judge는 Gate PASS를 높은 점수의 근거로 사용하면 안 된다. Gate PASS는 문항이 성립한다는 뜻일 뿐이며, 문제 점수는 target_score 대비 난이도와 선택지 품질을 별도로 엄격하게 평가한다. 정답이 맞고 역사 사실이 맞아도, 배점보다 쉽게 풀리거나 오답이 바로 제거되면 낮은 점수를 준다.

| 항목 | 배점 | 평가 초점 |
|---|---:|---|
| 1. 목표 난이도 적합성 | 4점 | 실제 풀이 난이도가 target_score와 맞는가 |
| 2. 선택지 품질 | 6점 | 선택지 5개가 발문 응답 범주에 맞고, 중복·포함 관계가 없으며, 유효 매력 오답이 충분한가 |

### 12.1 목표 난이도 적합성 4점

목표 난이도 적합성은 아래 4개 요소를 target_score 기준표와 대조해 채점한다.

| 평가 요소 | 의미 |
|---|---|
| 단서 묶음 수 | 정답 도출에 필요한 독립 단서 묶음 수 |
| 단서 유형 | A 직접 식별, B 대표 추론, C 우회·사료 중 무엇인지 |
| 풀이 단계 | 식별 후 바로 선택, 식별 후 비교, 전후·인과·세부 차이 판단 중 무엇인지 |
| 지식 깊이 | 대표 개념, 심화 표준 개념, 세부 제도·사건·단체·인물 구분 중 무엇인지 |

| 점수 | 기준 |
|---:|---|
| 4점 | 1점은 4개 요소가 기준과 일치. 2·3점은 아래 주된 난이도 기제 중 하나가 목표 수준으로 실제 작동 |
| 3점 | 4개 요소 중 3개가 target_score 기준과 일치 |
| 2점 | 4개 요소 중 2개가 target_score 기준과 일치 |
| 1점 | 4개 요소 중 1개만 target_score 기준과 일치 |
| 0점 | 4개 요소가 모두 불일치하거나 실제 난이도가 target_score와 명백히 다름 |

단서 유형은 다음 3개 중 하나로만 분류한다. 여러 유형이 섞이면 정답을 확정하는 데 가장 강하게 작동하는 단서를 기준으로 분류한다.

| 단서 유형 | 이름 | 판정 기준 | 예시 |
|---|---|---|---|
| A | 직접 식별 단서 | 정답 대상의 명칭, 별칭, 대표 유물·대표 제도·대표 키워드가 직접 또는 거의 직접 제시되어 대상 식별이 바로 가능함 | `훈민정음`, `집현전`으로 세종 식별, `소도`, `천군`으로 삼한 식별 |
| B | 대표 추론 단서 | 정답명은 직접 나오지 않지만, 대표 활동·대표 배경·대표 결과를 연결하면 대상을 식별할 수 있음 | `민족 자결주의`, `만세 시위`로 3·1 운동 추론, `국채 보상`, `대구에서 시작`으로 국채 보상 운동 추론 |
| C | 우회·사료 단서 | 정답명과 대표 키워드가 직접 나오지 않고, 사료 문장·우회 표현·복수 자료·전후 관계를 해석해야 대상 또는 정답 조건을 확정할 수 있음 | 두 사건 사이 시기 판단, 사료의 주장 해석 후 단체 활동 구분, 비슷한 제도·정책의 세부 차이 판단 |

target_score별 목표 난이도 기준은 다음과 같다.

| 기준 | 1점 | 2점 | 3점 |
|---|---|---|---|
| 단서 묶음 수 | 핵심 단서 1묶음으로 식별 가능 | 고정하지 않음. 단서 수 자체는 2점 조건이 아님 | 고정하지 않음. 단서 수 자체는 3점 조건이 아님 |
| 단서 유형 | A 직접 식별 단서가 적합 | A·B·C 모두 가능. 대표 추론이 주된 난이도이면 B | A·B·C 모두 가능. 사료·우회 해석이 주된 난이도이면 C |
| 풀이 단계 | 식별 후 바로 선택 | 대표 추론, 식별 후 표준 사실 비교, 넓은 시기·전후 판단, 중간 수준의 가까운 선지 비교 중 하나가 필요 | 정밀 연대·관계 판단 또는 대상 식별 후 세부 사실 판단 등이 실제로 필요 |
| 지식 깊이 | 대표 개념 | 심화 시험의 표준 개념 | 세부 지식이 주된 난이도일 수 있으나 모든 3점 문항의 필수조건은 아님 |

과잉 확정 단서 규칙은 다음과 같다.

| 상황 | 처리 |
|---|---|
| target_score 1점인데 정답 대상을 확정하는 독립 단서가 3묶음 이상이고, 실제 풀이가 식별 후 비교로 바뀜 | 목표 난이도 적합성에서 `단서 묶음 수`와 `풀이 단계`를 불일치로 본다 |
| target_score 2점인데 대표 단서 하나만으로 정답 선지까지 바로 확정됨 | 다른 주된 난이도 기제가 없으면 1점형으로 감점한다 |
| target_score 2점인데 자료명·발문에 정답 대상명이 직접 드러남 | 별도 대표 사실·시기·활동 비교가 필요하면 허용하고, 그렇지 않으면 감점한다 |
| target_score 2점인데 오답이 먼 시대·주제에 있음 | 가까운 선지 비교가 주된 난이도 기제일 때만 난이도에서 감점한다. 다른 기제가 작동하면 그 이유만으로 감점하지 않는다 |
| target_score 3점인데 대상 식별 후 별도 판단 없이 대표 사실을 바로 선택함 | 다른 주된 난이도 기제가 없으면 목표 난이도를 감점한다 |
| target_score 3점인데 자료명·발문에 정답 대상명이 직접 드러남 | 별도 세부 사실·연대·관계 판단이 필요하면 허용하고, 그렇지 않으면 감점한다 |
| target_score 3점인데 오답이 먼 시대·주제에 있음 | 가까운 선지 비교형일 때만 난이도에서 감점한다. 다른 기제가 작동하면 그 이유만으로 감점하지 않는다 |

목표 난이도 감점 고정표는 다음과 같다. 같은 문항에 여러 조건이 걸리면 더 낮은 상한을 적용한다.

| 상황 | 목표 난이도 상한 |
|---|---:|
| 정답 직접 노출, 정답 선지 복사·의역, 복수 정답, 역사 사실 오류 | Gate FAIL이므로 점수 채점 안 함 |
| target_score 2점에서 대표 추론이 정답 도출에 실제로 필요함 | 4점 |
| target_score 2점에서 대상 식별 후 표준 활동·정책·시기 비교가 실제로 필요함 | 4점 |
| target_score 2점에서 넓은 시기·전후 판단 또는 중간 수준의 가까운 선지 비교가 실제로 필요함 | 4점 |
| target_score 2점에서 위 기제가 있으나 비교 부담이 약함 | 3점 |
| target_score 2점에서 대상명이나 강한 단서가 보이고 별도 판단 부담도 매우 약함 | 2점 |
| target_score 2점에서 대표 단서 하나로 정답 선지까지 거의 바로 고름 | 1점 |
| target_score 3점에서 사료·우회 단서 해석이 정답 도출에 실제로 필요함 | 4점 |
| target_score 3점에서 정밀한 순서·전후·인과 판단이 실제로 필요함 | 4점 |
| target_score 3점에서 대상 식별 후 세부 사실 지식이 실제로 필요함 | 4점 |
| target_score 3점에서 가까운 선지 비교가 주된 판단으로 실제 작동함 | 4점 |
| target_score 3점에서 위 기제가 약하지만 식별 후 비교가 필요함 | 3점 |
| target_score 3점에서 대표 키워드만으로 정답 선지까지 바로 고름 | 1~2점 |

목표 난이도 예시:

| 문항 상황 | 판단 |
|---|---|
| 1점 문항에서 `소도`, `천군`으로 삼한을 식별하고 바로 고름 | 4요소 대부분 1점 기준과 일치 |
| 2점 문항에서 `민족 자결주의`, `만세 시위`로 3·1 운동을 추론한 뒤 관련 활동을 고름 | 4요소 대부분 2점 기준과 일치 |
| 3점 문항에서 (가), (나) 두 사건을 식별하고 그 사이 시기에 있었던 사실을 고름 | 4요소 대부분 3점 기준과 일치 |
| 1점 문항인데 고려 태조를 확정하는 단서가 3개 이상이고, 선택지는 고려 왕 정책 비교를 요구함 | 단서 묶음 수와 풀이 단계가 1점 기준에서 벗어남 |

### 12.2 선택지 품질 6점

선택지 품질은 Gate PASS 문항만 6점에서 시작해 결함마다 감점한다. Gate FAIL 사유는 점수 감점으로 처리하지 않는다.

최종 점수는 `max(0, 6 - 총 감점)`으로 계산한다.

공통 감점 기준은 다음과 같다.

| 결함 | 감점 |
|---|---:|
| 선택지 1개가 발문이 요구하는 응답 범주에서 벗어남 | -1 |
| 선택지 2개 이상이 발문 응답 범주에서 벗어남 | -2 또는 G2/G3 검토 |
| 약한 중복·포함 관계 1쌍 | -1 |
| 중복·포함 관계 2쌍 이상 | -2 또는 G3 검토 |
| 정답 선지만 길이·구체성·문장 형식에서 약하게 튐 | -1 |
| 정답 선지만 강하게 튀어 역사 지식 없이 정답 추정 가능 | G6 FAIL |
| 오답 중 역사적으로 성립하지 않는 선지 있음 | G5 FAIL |

일반 5지선다와 조합형·순서형은 서로 다른 방식으로 감점한다.

#### 12.2.1 일반 5지선다

일반 5지선다는 선택지 5개가 각각 독립된 역사 명제인 문항이다. 이 유형은 유효 매력 오답 수와 시대·주제권 근접성을 본다.

유효 매력 오답은 단순히 같은 시대·같은 분류인 오답이 아니다. 아래 3개 조건을 모두 만족해야 한다.

| 조건 | 설명 |
|---|---|
| 역사 사실성 | 오답 문장 자체가 한국사 사실로 성립한다. 성립하지 않으면 G5 FAIL이지 점수 감점이 아니다 |
| 범주 접근성 | 정답과 같은 시대권·인접 시대 또는 같은 주제·정책·사건·인물·단체 범주에 걸쳐 있다 |
| 발문 적용 후 잔존성 | 발문 단서를 적용한 뒤에도 바로 제거되지 않고 실제 비교 후보로 남는다 |

Gate PASS 이후에는 오답 4개가 모두 역사적으로 성립한다고 전제한다. 따라서 점수표에서는 `정상 오답 수`를 세지 않는다. 대신 오답 4개 중 몇 개가 정답과 같은 시대권 또는 같은 주제권 안의 비교 후보인지 본다.

LLM judge는 오답이 역사적으로 맞다는 이유만으로 유효 매력 오답으로 세면 안 된다. 발문 단서를 적용한 뒤 시대·주제·조건 차이로 바로 제거되는 오답은 유효 매력 오답이 아니다. 2·3점 모두 가까운 선지 비교가 주된 기제인 문항에서만 이 수를 난이도 판단에 사용한다.

1점 문항은 어려운 매력 오답을 강제하지 않는다. 대신 오답이 너무 먼 시대·무관 주제로 흩어지면 감점한다.

| 결함 | 감점 |
|---|---:|
| 같은 시대권 또는 같은 주제권 오답 3~4개 | 0 |
| 같은 시대권 또는 같은 주제권 오답 2개 | -1 |
| 같은 시대권 또는 같은 주제권 오답 1개 | -2 |
| 같은 시대권 또는 같은 주제권 오답 0개 | -3 |

2·3점 문항은 가까운 선지 비교가 주된 난이도 기제일 때만 아래 근접성 기준을 난이도 판단에 적용한다.

| 결함 | 감점 |
|---|---:|
| 같은 시대권 또는 같은 주제권 오답 3~4개 | 0 |
| 같은 시대권 또는 같은 주제권 오답 2개 | -1 |
| 같은 시대권 또는 같은 주제권 오답 0~1개 | -2 |

가까운 선지 비교형 2·3점은 유효 매력 오답 수가 실제 비교 부담을 만드는지 목표 난이도에서 판단한다. 선택지 품질에서 같은 사유를 다시 감점하지 않는다.

| target_score | 기준 | 처리 |
|---|---|---|
| 2점 가까운 선지 비교형 | 중간 수준의 비교 부담이 실제로 남음 | 비교 부담의 강도에 따라 난이도에서 판단 |
| 3점 가까운 선지 비교형 | 정밀한 비교 부담이 실제로 남음 | 비교 부담의 강도에 따라 난이도에서 판단 |

#### 12.2.2 조합형·순서형·ㄱㄴㄷ 보기형

조합형·순서형·ㄱㄴㄷ 보기형에는 일반 5지선다의 유효 매력 오답 수 기준을 적용하지 않는다.

대상은 다음과 같다.

| 유형 | 예 |
|---|---|
| 조합형 | `① ㄱ, ㄴ ② ㄱ, ㄷ ③ ㄴ, ㄷ` |
| 순서형 | `① 나-가-라-다` |
| ㄱㄴㄷ 보기형 | 보기 ㄱ, ㄴ, ㄷ, ㄹ 중 옳은 것 또는 옳지 않은 것 고르기 |

이 유형은 보기·사건끼리 얼마나 가까운 시대·주제·전개 과정에 있어 실제로 헷갈리는지를 본다. 조합형·순서형이 출제되면 목표 난이도는 원칙적으로 3점형 후보로 본다. 실제 target_score가 1점·2점이면 목표 난이도 적합성에서 별도 감점한다.

공통 감점은 다음과 같다.

| 결함 | 감점 |
|---|---:|
| 조합 선택지 중 중복 조합 있음 | -1 또는 G3 검토 |
| 가능한 조합이 너무 적어 정답 조합만 튐 | -1 |
| 정답 조합만 설명형·장문형임 | -1 또는 G6 검토 |
| 보기 또는 사건 중 역사 오류 있음 | G4/G5 FAIL |
| 정답 조합·순서가 복수 가능 | G3 FAIL |

보기·사건 근접성 감점은 다음과 같다.

| 상태 | 감점 |
|---|---:|
| 보기·사건 3개 이상이 같은 전개 과정, 같은 시대권, 같은 주제권 안에 있어 실제 비교가 필요함 | 0 |
| 보기·사건 2개만 가까운 비교 후보이고 나머지는 쉽게 제거됨 | -1 |
| 보기·사건 1개만 가까운 비교 후보임 | -2 |
| 보기·사건 대부분이 먼 시대·무관 주제라 정답 조합·순서가 바로 보임 | -3 |

오답 판단 예시:

| 상황 | 유효 매력 오답인가 |
|---|---|
| 대동법 문항에서 균역법, 영정법처럼 조선 후기 수취 제도와 비교해야 하는 오답 | 예 |
| 고려 태조 문항에서 경종 전시과, 광종 노비안검법, 성종 12목처럼 모두 고려 왕 정책이지만 발문 단서 적용 후 바로 제거되는 오답 | 보통 아님 |
| 통일 신라 경제 상황 문항에서 고려 벽란도, 고려 은병, 조선 후기 공인처럼 시대 식별 후 바로 제거되는 오답 | 보통 아님 |
| 흥선 대원군 정책 문항에서 통리기무아문 설치처럼 개화 정책과 헷갈릴 수 있으나 주체·시기 비교가 필요한 오답 | 예 가능 |
| 사화 순서 문항에서 무오사화, 갑자사화, 기묘사화, 을사사화가 제시됨 | 조합형·순서형 근접성 좋음 |
| 고조선, 고려 과거제, 임진왜란, 새마을 운동을 순서로 묻는 문항 | 조합형·순서형 근접성 낮음 |

발문이 `경제 상황`을 물으면 무역항, 화폐, 토지 제도, 작물, 상업 주체가 모두 경제 상황에 들어갈 수 있다. 이 경우 응답 범주 적합성은 충족할 수 있다. 오답이 쉽게 제거되는 문제는 target_score 2점과 가까운 선지 비교형 3점에서 난이도 판단에 반영한다. target_score 1점과 다른 기제의 3점에는 유효 매력 오답 수를 강제하지 않는다.

발문이 `정책`을 물으면 선택지 5개가 정책·제도 진술이어야 한다. 인물명, 문화유산, 사건명처럼 정책이 아닌 단위가 섞이면 선택지 품질 감점 또는 Gate 검토 대상이다.

| 선택지 묶음 예 | 응답 범주 판정 |
|---|---|
| 발문이 경제 상황을 묻고, 선택지가 무역항·화폐·토지 제도·작물·상업 주체임 | 응답 범주가 모두 경제 상황이므로 구성은 가능 |
| 발문이 정책을 묻고, 선택지가 모두 수취 제도·토지 제도·행정 제도임 | 구성 좋음 |
| 발문이 문화유산을 묻는데 선택지에 인물 활동이나 정치 제도가 섞임 | 응답 범주 감점 |
| 두 선택지가 같은 내용을 표현만 바꿔 반복함 | 중복 관계로 감점 |
| 한 선택지가 다른 선택지의 상위 개념이라 둘 다 정답처럼 보일 수 있음 | G3 또는 선택지 구성 감점 |

## 13. 문제 평가항목별 예시

| 항목 | 좋은 예 | 감점 예 |
|---|---|---|
| 목표 난이도 적합성 | 2점 문항에서 대표 단서 2개로 대상을 식별하고 선택지에서 활동을 비교함 | 2점 문항인데 정답명에 가까운 단서 하나로 바로 선택 가능 |
| 선택지 품질 | 선택지 5개가 발문 응답 범주에 맞고, 중복이 없으며, 발문 단서 적용 후에도 비교해야 하는 오답이 있음 | 선택지 범주가 섞이거나, 중복이 있거나, 오답이 모두 바로 제거됨 |

## 14. target_score별 판정 예시

이 절은 평가자가 target_score 기준을 실제 문항에 적용할 때 참고하는 예시이다. 예시는 문항 유형을 설명하기 위한 것이며, 실제 정답·오답 구성은 역사 사실에 맞게 작성되어야 한다.

### 14.1 target_score 1점

1점 문항은 "알면 바로 고르는 식별형"에 가깝다.

| 평가 요소 | 1점 적합 예 | 감점 또는 부적합 예 |
|---|---|---|
| 목표 난이도 | 대표 단서 1묶음으로 시대·인물·사건·제도를 식별하고 바로 정답 선택 가능 | 사료 해석, 전후 관계, 세부 비교가 필요함 |
| 선택지 품질 | 선택지 5개가 발문 응답 범주에 맞고 중복이 없으며, 오답이 같은 시대권 또는 같은 주제권 안에 있음 | 범주 밖 선택지가 있거나, 중복이 있거나, 오답이 시대·주제에서 지나치게 흩어져 있으면 감점 |

예시 패턴:

| 상황 | 판단 |
|---|---|
| 발문에 "훈민정음", "집현전" 같은 대표 단서가 있고 세종 관련 사실을 고르게 함 | 1점 적합 가능 |
| 발문에 "소도", "천군"이 있고 삼한의 특징을 고르게 함 | 1점 적합 가능 |
| 1점인데 두 사건 사이의 시기를 묻고 오답이 모두 같은 시대 흐름 안에 있음 | 목표 난이도 부적합. 실제 난이도는 2~3점형 |
| 1점인데 정답 대상 식별 후 오답이 모두 바로 제거됨 | 쉬운 식별형으로는 허용. 다만 오답이 같은 시대권 또는 같은 주제권 안에 있지 않으면 선택지 품질 감점 |

### 14.2 target_score 2점

2점 문항은 한능검 심화에서 가장 넓게 쓰이는 기본 난이도이다. 대표 추론, 식별 후 표준 사실 비교, 넓은 시기·전후 판단, 중간 수준의 가까운 선지 비교 중 하나가 실제 풀이에 작동하면 성립할 수 있다.

| 평가 요소 | 2점 적합 예 | 감점 또는 부적합 예 |
|---|---|---|
| 목표 난이도 | 위 주된 난이도 기제 중 하나가 표준 수준으로 실제 작동함 | 대표 키워드 하나로 바로 정답을 고르거나, 반대로 정밀한 복합 판단이 필요함 |
| 선택지 품질 | 선택지 5개가 발문 응답 범주에 맞고 중복·외형 편향이 없음 | 범주 밖 선택지, 중복, 허위 사실, 외형 편향이 있음 |

예시 패턴:

| 상황 | 판단 |
|---|---|
| 자료에서 "민족 자결주의", "만세 시위"로 3·1 운동을 식별한 뒤 관련 사실을 고르게 함 | 2점 적합 가능 |
| 자료에서 단체를 식별하고 그 단체의 활동을 선택지에서 고르게 함 | 2점 적합 가능 |
| 자료명에 대상이 직접 보이지만 선택지에서 별도 대표 정책을 비교해야 함 | 2점 적합 가능 |
| 2점인데 발문에 정답명과 정답 선지 핵심 표현이 거의 그대로 있음 | G6 검토. 같은 역사 명제 반복이면 Gate FAIL |
| 2점인데 단서가 낯선 사료뿐이고 오답도 모두 같은 전개 과정 안에 있음 | 2점보다 어려울 수 있음 |
| 2점인데 가까운 선지 비교를 주된 기제로 삼았으나 오답이 모두 바로 제거됨 | 목표 난이도 감점 |

### 14.3 target_score 3점

3점 문항은 한 가지 이상의 주된 난이도 기제가 실제 풀이에 작동해야 한다. 모든 문항이 복합 판단형이거나 가까운 오답 비교형일 필요는 없다.

| 평가 요소 | 3점 적합 예 | 감점 또는 부적합 예 |
|---|---|---|
| 목표 난이도 | 사료·우회 단서 해석, 정밀 연대·관계 판단, 세부 지식, 가까운 선지 비교 중 하나가 정답 도출에 실제로 필요함 | 어떤 기제도 없이 대표 키워드 하나로 정답 선지까지 바로 선택 가능 |
| 선택지 품질 | 선택지 5개가 발문 응답 범주에 맞고 중복·허위 결합·외형 편향이 없음 | 범주 밖 선택지, 중복, 허위 결합 또는 정답 외형 편향이 있음 |

예시 패턴:

| 상황 | 판단 |
|---|---|
| (가), (나) 두 사건을 각각 식별하고 그 사이 시기에 있었던 사실을 고르게 함 | 3점 적합 가능 |
| 여러 사건 또는 자료를 일어난 순서대로 배열하게 함 | 3점 적합 가능 |
| 같은 시대의 유사 제도·정책·단체 활동을 구분해야 함 | 3점 적합 가능 |
| 대상을 비교적 쉽게 식별해도 별도의 세부 업적·정책·사건 지식이 필요함 | 3점 적합 가능 |
| 3점인데 "나운규, 1926년, 영화"만 보고 바로 아리랑을 떠올려 선택 가능하고 오답도 멀리 떨어져 있음 | 3점 부적합. Gate PASS라도 난이도 감점 |
| 3점인데 정답 선지만 발문·자료의 핵심 표현을 거의 그대로 반복함 | Gate FAIL 가능 |

## 18. 사람용 빠른 보기

이 절은 위의 v1.8.6 기준을 사람이 빠르게 적용할 수 있도록 풀어쓴 요약이다. 별도 평가표가 아니다. Gate, 배점, 점수 계산은 위 기준과 완전히 같다.

### 18.1 사람용 평가 순서

| 순서 | 작업 | 판단 |
|---:|---|---|
| 1 | Gate G1~G6을 먼저 본다 | 하나라도 FAIL이면 점수 채점하지 않고 0점 처리 |
| 2 | Gate FAIL 사유가 G1/G2/G5/G6뿐인지 본다 | 부분 수정 가능하면 repair |
| 3 | Gate FAIL에 G3 또는 G4가 포함되는지 본다 | 정답 성립·자료 고증이 흔들린 것이므로 regenerate |
| 4 | Gate PASS인 문항만 문제 10점 기준으로 채점한다 | 목표 난이도 적합성 4점 + 선택지 품질 6점 |
| 5 | Codex 평가와 Human 평가를 비교한다 | Gate 판정 일치와 점수 차이를 따로 본다 |

### 18.2 목표 난이도 적합성 4점 빠른표

Gate PASS 후, 문항의 배점 행에서 가장 가까운 칸을 고른다.

| 배점 | 4점 | 3점 | 2점 | 1점 | 0점 |
|---:|---|---|---|---|---|
| 1점 | 대표 단서 1묶음으로 시대·인물·사건·제도를 식별하고 바로 정답 선택 가능 | 거의 바로 풀리지만 선택지 비교가 약간 필요하거나 단서가 조금 많음 | 대상 식별 후 정책·활동·시기 비교가 필요해 2점형에 가까움 | 사료 해석, 사건 순서, 전후 관계, 세부 비교가 필요해 3점형에 가까움 | 1점 식별형으로 볼 수 없을 만큼 배점과 맞지 않음 |
| 2점 | 대표 추론·표준 사실 비교·넓은 시기 판단·중간 수준의 가까운 선지 비교 중 하나가 실제로 작동함 | 주된 기제가 있으나 부담이 약함 | 대표 키워드 하나로 바로 풀리거나, 반대로 정밀한 관계 판단이 필요함 | 너무 쉽거나 너무 어려워 2점형 특징이 거의 없음 | 2점 문항으로 볼 수 없을 만큼 배점과 맞지 않음 |
| 3점 | 사료 해석·정밀 연대·세부 지식·가까운 선지 비교 중 하나가 주된 난이도로 실제 작동함 | 주된 기제가 있으나 부담이 약함 | 대상 식별 후 표준 활동·정책 비교 수준임 | 대표 키워드 하나로 정답 선지까지 바로 선택함 | 3점 문항으로 볼 수 없을 만큼 배점과 맞지 않음 |

2점 문항은 아래 주된 난이도 기제 표를 우선 적용한다.

| 2점 문항 상황 | 난이도 점수 |
|---|---:|
| 대표 추론, 식별 후 표준 사실 비교, 넓은 시기·전후 판단, 중간 수준의 가까운 선지 비교 중 하나가 실제 작동 | 4점 |
| 주된 난이도 기제가 있으나 판단 부담이 약함 | 3점 |
| 대상명·자료명이 직접 보이고 별도 판단 부담도 매우 약해 1점형에 가까움 | 2점 |
| 대표 단서 하나만 보고 정답 선지까지 거의 바로 고름 | 1점 |
| 2점 문항 구조가 아님 | 0점 |

### 18.3 선택지 품질 6점 빠른표

선택지 품질은 Gate PASS 문항만 6점에서 시작해 결함마다 감점한다. 정답 노출, 허위 오답, 복수 정답은 점수 감점이 아니라 Gate에서 먼저 처리한다.

공통 감점:

| 결함 | 감점 |
|---|---:|
| 선택지 1개가 발문 응답 범주에서 벗어남 | -1 |
| 선택지 2개 이상이 발문 응답 범주에서 벗어남 | -2 또는 Gate 검토 |
| 약한 중복·포함 관계 1쌍 | -1 |
| 중복·포함 관계 2쌍 이상 | -2 또는 G3 검토 |
| 정답 선지만 길이·구체성·형식에서 약하게 튐 | -1 |
| 정답 추정이 가능할 정도로 튐 | G6 FAIL |
| 오답에 역사적으로 성립하지 않는 문장이 있음 | G5 FAIL |

일반 5지선다 감점:

| target_score | 기준 | 감점 |
|---|---|---:|
| 1점 | 같은 시대권 또는 같은 주제권 오답 3~4개 | 0 |
| 1점 | 같은 시대권 또는 같은 주제권 오답 2개 | -1 |
| 1점 | 같은 시대권 또는 같은 주제권 오답 1개 | -2 |
| 1점 | 같은 시대권 또는 같은 주제권 오답 0개 | -3 |
| 2점 | 가까운 선지 비교가 주된 기제임 | 비교 부담을 난이도 판정에 사용하며 선택지 품질에서 중복 감점하지 않음 |
| 2점 | 다른 기제가 주된 난이도임 | 가까운 오답 수만으로 선택지 품질을 감점하지 않음 |
| 3점 | 가까운 선지 비교가 주된 기제임 | 매력 오답 수를 난이도 판정에 사용 |
| 3점 | 다른 기제가 주된 난이도임 | 가까운 오답 수만으로 선택지 품질을 감점하지 않음 |

조합형·순서형·ㄱㄴㄷ 보기형 감점:

| 상태 | 감점 |
|---|---:|
| 보기·사건 3개 이상이 같은 전개 과정, 같은 시대권, 같은 주제권 안에 있어 실제 비교가 필요함 | 0 |
| 보기·사건 2개만 가까운 비교 후보이고 나머지는 쉽게 제거됨 | -1 |

### 18.5 사람용 일치율 계산 기준

| 비교 항목 | 일치 기준 |
|---|---|
| Gate 일치 | Codex와 Human의 최종 Gate가 모두 PASS, FAIL, uncertain 중 같은 값 |
| 조치 일치 | Codex와 Human의 조치가 accept, repair, regenerate, needs_verification 중 같은 값 |
| 점수 일치 | Gate PASS 문항에서 사람용 10점 점수 차이가 1점 이하 |
| 최종 일치 | Gate가 같고, Gate PASS 문항은 점수 차이가 1점 이하 |

발표용으로는 `Gate 일치율`과 `최종 일치율`을 분리해 말한다. Gate 일치율은 문항 성립 여부 판단의 일치도이고, 최종 일치율은 문항 품질 점수까지 포함한 일치도이다.
