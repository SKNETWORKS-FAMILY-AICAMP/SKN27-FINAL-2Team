# 한국민족문화대백과사전 detail 적재 가이드

대상은 `etl/raw_data/한국민족문화대백과사전/articles_detail.jsonl`만 사용한다.

## 전처리

```powershell
.\.venv\Scripts\python.exe etl\preprocessing\history\preprocess_aks_encyclopedia.py
```

결과는 `etl/preprocessing/history/processed/aks_encyclopedia.documents.jsonl`과 `aks_encyclopedia.chunks.jsonl`이다.

- 문서 단위: `eid`
- 청크: 본문 기준 1,200자, 150자 겹침
- 모든 청크: 제목·정의·별칭 포함
- 첫 청크: 요약 추가
- 메타데이터: 시대, 분야, 1차 유형, 콘텐츠 유형, 2차 유형

## 임베딩·적재·인덱스

```powershell
.\.venv\Scripts\python.exe etl\preprocessing\history\embedding\embed_chunks_to_pgvector.py `
  --chunk-file aks_encyclopedia.chunks.jsonl `
  --source-type aks_encyclopedia `
  --limit 1000000 `
  --create-index
```

`--source-type aks_encyclopedia`로 기존 수집 출처의 미임베딩 청크가 함께 처리되는 일을 막는다. HNSW 인덱스는 이미 있으면 유지되고 새 청크가 자동 반영된다.

별칭을 추가하는 등 `chunk_text`가 변경되면 UPSERT가 해당 행의 기존 임베딩을 비운다. 같은 적재 명령을 다시 실행하면 변경된 청크만 재임베딩한다.
