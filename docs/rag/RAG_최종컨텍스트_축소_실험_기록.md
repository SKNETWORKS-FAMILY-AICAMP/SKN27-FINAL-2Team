# 최종 컨텍스트 축소 실험 기록

## 목적

LLM에 전달하는 최종 근거를 줄여 검색 잡음을 낮추고 RAGAS Context Precision을 높이는지 확인했다.

## 적용 내용

`app/chatbot/rag_service.py`에서 다음 두 가지를 적용했다.

1. 질문의 핵심어가 제목 또는 본문에 없는 검색 결과를 최종 근거 후보에서 제외
2. LLM 전달 문서 수를 기존 Top 5에서 Top 3으로 축소

이미지 질의는 기존처럼 제한하지 않았다.

## 평가 결과

| 평가 항목 | 적용 전 | 적용 후 | 변화 |
|---|---:|---:|---:|
| 연결성(Graph) | 100.0% | 100.0% | 0.0%p |
| 검색 속도 | 6.34s | 6.94s | +0.60s |
| LLM 답변 생성 속도 | 3.54s | 6.47s | +2.93s |
| 전체 응답 속도 | 9.87s | 13.41s | +3.54s |
| RAGAS Context Precision | 0.67 | 0.69 | +0.02 |
| RAGAS Context Recall | 0.88 | 0.56 | -0.32 |
| RAGAS Faithfulness | 0.90 | 0.76 | -0.14 |
| RAGAS Answer Relevance | 0.79 | 0.77 | -0.02 |

## 결론

Context Precision 상승 폭은 0.02로 작았고, 필요한 근거까지 제외되어 Context Recall과 Faithfulness가 기준 아래로 하락했다. 속도도 개선되지 않았으므로 이 방식은 채택하지 않는다.

해당 최종 핵심어 필터와 Top 3 제한은 원복했다. 이후 Precision 개선은 최종 문서 수를 일괄 축소하기보다 검색 후보 단계의 랭킹 품질을 개선하는 방향으로 검토한다.
