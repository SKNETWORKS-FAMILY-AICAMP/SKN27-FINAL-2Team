# 한능검 SLLM 문항 평가지표 v1.7.1

## 1. 목적

이 문서는 한국사능력검정시험 심화형 문항을 LLM judge가 평가하기 위한 순수 문항 품질 기준이다.

현재 기준은 Evidence Pack, target_period, target_topic, target_major_type, target_minor_type을 평가하지 않는다. 문항 자체의 성립 여부와 품질만 평가한다.

## 2. 운영 원칙

- Evidence Pack은 사용하지 않는다.
- target_period, target_topic, target_major_type, target_minor_type은 평가하지 않는다.
- 한 번에 문항 1개만 평가한다.
- 여러 문항이 입력되면 가장 앞 번호 1개만 평가하고, 나머지는 평가하지 않는다.
- 입력된 question_id 외의 문항을 언급하거나 비교하지 않는다.
- Gate는 점수보다 우선한다.
- Gate 하나라도 FAIL이면 regenerate로 처리한다.
- Gate 통과 후에만 문제 10점, 해설 5점을 채점한다.
- 역사 사실성 uncertain은 PASS가 아니며 검증 보류 상태로 기록한다.
- 문항 형식이 그럴듯하다는 이유로 내용 검증을 생략하지 않는다.

## 3. 복수 문항 입력 처리

| 상황 | 처리 |
|---|---|
| 문항 1개 입력 | 해당 문항만 평가 |
| 문항 여러 개 입력 | 가장 앞 번호 1개만 평가 |
| "41~50번 평가"처럼 범위 입력 | 41번만 평가하고 다음 문항 진행 대기 |
| 응답 중 다른 문항 언급 | 평가 오류로 간주 |

## 4. uncertain 처리 규칙

| 상태 | 처리 |
|---|---|
| 명백한 오류 | Gate FAIL |
| 역사 사실성 uncertain, 정답 유일성에 영향 없음 | Gate 보류, 후속 검증 필요 |
| 역사 사실성 uncertain, 정답 유일성에 영향 있음 | G7 위험으로 regenerate 권장 |
| 외부 검증 후 사실로 확인 | PASS |
| 외부 검증 후 오류로 확인 | Gate FAIL |
| 외부 검증 불가 | 점수 채점 보류, needs_verification |

## 5. Gate

Gate는 문항 성립 조건이다. 하나라도 FAIL이면 점수 평가를 진행하지 않고 regenerate로 처리한다.

| Gate | 항목 | FAIL 기준 |
|---|---|---|
| G1 | 필수 문제 입력 존재 | 발문, 선택지, 정답, target_score 중 하나라도 없음 |
| G2 | 5지선다 형식 | 선택지가 정확히 5개가 아니거나 빈 선택지가 있음 |
| G3 | 정답 표시 | 정답이 ①~⑤ 또는 1~5 중 정확히 하나가 아님 |
| G4 | 배점 형식 | target_score가 1점, 2점, 3점 중 하나가 아님 |
| G5 | 발문-선지 응답 형식 | 발문이 요구하는 답변 형식과 선택지 형식이 맞지 않음 |
| G6 | 의미 판단 가능성 | 문장 파손, 누락, 비문 때문에 의미 판단이 불가능함 |
| G7 | 정답 유일성 | 발문 조건을 만족하는 선택지가 0개 또는 2개 이상 |
| G8 | 정답 역사 사실성 | 표시 정답이 발문 조건 또는 한국사 사실과 명백히 충돌함 |
| G9 | 발문·자료 역사 사실성 및 내부 일관성 | 발문·자료의 핵심 단서가 역사 사실과 명백히 충돌하거나, 자료 내부 인물·시기·사건·저작·발화 주체가 명백히 모순됨 |
| G10 | 오답 역사 사실성 | 오답 4개 중 하나라도 한국사 사실과 명백히 충돌하는 허위 서술이면 FAIL. 세부 사실 확인이 애매하면 FAIL이 아니라 Gate uncertain으로 기록 |
| G11 | 발문·자료-정답 선지 직접 대응 | 발문·자료의 핵심 표현이 정답 선지에 그대로 또는 거의 같은 의미로 반복되어 문장 매칭만으로 정답 확정 가능 |

## 6. G10 오답 역사 사실성 세부 규칙

| 오답 유형 | 판정 |
|---|---|
| 역사적으로는 맞지만 발문 조건과 맞지 않음 | PASS |
| 다른 시대·인물·제도에 대한 역사적으로 맞는 사실 | PASS |
| 서로 다른 역사 사실을 한 주체의 활동처럼 잘못 결합 | FAIL |
| 사건 순서, 주체, 시기, 결과를 명백히 잘못 연결 | FAIL |
| 실제 역사에서 성립하지 않는 허위 서술 | FAIL |
| 세부 사실 확인이 애매함 | Gate uncertain, 후속 검증 필요 |

## 7. G11 직접 대응 세부 규칙

정답 선지의 핵심 표현에는 아래가 포함된다.

| 유형 | 예시 |
|---|---|
| 고유명사 | 아리랑, 신민회, 사헌부 |
| 사건명 | 갑신정변, 병인양요 |
| 제도명·기관명 | 정방, 사헌부, 통리기무아문 |
| 별칭 | 홍의 장군 |
| 핵심 기능 표현 | 관리의 비리를 감찰하였다 |
| 핵심 결과 표현 | 인사권을 장악하였다 |
| 핵심 활동 표현 | 의령에서 의병을 이끌었다 |

| 경우 | 판정 |
|---|---|
| 발문에 "나운규, 1926년, 영화"가 있고 정답이 "아리랑" | Gate PASS, 난이도 감점 가능 |
| 발문에 "아리랑"이 있고 정답이 "아리랑" | G11 FAIL |
| 발문 표현과 정답 선지의 동사·목적어가 거의 같음 | G11 FAIL |
| 발문의 기능·결과·활동 표현이 정답 선지에 그대로 반복됨 | G11 FAIL |
| 발문은 강한 단서만 주고 정답 선지가 별도 지식으로 연결됨 | Gate PASS, 난이도 감점 가능 |
| 자료 해석형에서 정답 선지가 자료 문장을 단순 반복함 | G11 FAIL 또는 난이도 감점 |
| 자료 해석형에서 정답 선지가 자료 내용에서 한 단계 추론된 역사적 의미를 제시함 | PASS |
| 자료 표현이 선택지 5개에 같은 방식으로 반영되어 있고, 정답 선지만 튀지 않음 | Gate PASS 가능, 난이도에서 판단 |
| 정답 선지만 자료 표현을 거의 그대로 가져옴 | G11 FAIL |

## 8. Gate 적용 절차

LLM judge는 Gate 판정 전에 아래 절차를 먼저 수행한다.

| 단계 | 작업 |
|---|---|
| 1 | 입력된 question_id의 문항 1개만 평가 대상인지 확인 |
| 2 | 발문이 요구하는 조건을 한 문장으로 추출 |
| 3 | 자료·대화·제시문 속 핵심 역사 사실을 문장 단위로 추출 |
| 4 | 정답 선지의 핵심 표현 추출 |
| 5 | 선택지 5개 각각의 역사 명제를 추출 |
| 6 | 선택지별로 역사적으로 성립하는가와 발문 조건에 부합하는가를 분리 판단 |
| 7 | 발문·자료와 정답 선지의 핵심 표현이 직접 대응하는지 검사 |
| 8 | 자료 내부의 인물, 시기, 사건, 저작, 발화 주체가 서로 모순되는지 검사 |
| 9 | 이 문항을 탈락시킬 수 있는 가장 강한 이유를 최대 3개 찾고 Gate를 재검토 |

## 9. 선택지 검증 양식

G7, G10 판단 전에 선택지별로 아래 정보를 작성한다.

| 선택지 | 역사 명제 | 역사적으로 성립? | 발문 조건에 부합? |
|---|---|---|---|
| ① | 선택지 내용을 역사 명제로 환원 | yes/no/uncertain | yes/no/uncertain |
| ② | 선택지 내용을 역사 명제로 환원 | yes/no/uncertain | yes/no/uncertain |
| ③ | 선택지 내용을 역사 명제로 환원 | yes/no/uncertain | yes/no/uncertain |
| ④ | 선택지 내용을 역사 명제로 환원 | yes/no/uncertain | yes/no/uncertain |
| ⑤ | 선택지 내용을 역사 명제로 환원 | yes/no/uncertain | yes/no/uncertain |

판정 규칙은 다음과 같다.

- 역사적으로 성립하지만 발문 조건에 맞지 않음: 정상 오답
- 역사적으로 성립하지 않음: G10 FAIL
- 발문 조건에 부합하는 선지가 2개 이상: G7 FAIL
- 불확실한 선택지가 정답 가능성을 흔듦: G7 FAIL 또는 regenerate 권장

## 10. 평가표

Gate 통과 후 평가한다. 문제 품질 10점, 해설 품질 5점, 총 15점이다. 각 소항목은 yes = 1점, no/uncertain = 0점이다.

| 구분 | 항목 | 소항목 | 1점 기준 |
|---|---|---|---|
| 문제 10점 | 난이도 설계 | 단서 묶음 수 | 정답 도출에 필요한 독립 단서 묶음 수가 target_score 기준과 맞다 |
| 문제 10점 | 난이도 설계 | 단서 간접성 | 단서가 직접 명칭, 대표 키워드, 우회 표현 중 target_score 기준과 맞는 수준이다 |
| 문제 10점 | 난이도 설계 | 풀이 단계 | 정답 도출 과정이 단순 식별, 식별 후 비교, 관계 판단 중 target_score 기준과 맞다 |
| 문제 10점 | 난이도 설계 | 지식 깊이 | 필요한 역사 지식이 대표 개념, 심화 기본 개념, 세부 개념 중 target_score 기준과 맞다 |
| 문제 10점 | 난이도 설계 | 정답 노출 조절 | G11에는 해당하지 않지만, 단서 강도가 target_score보다 과도하게 쉽지 않다 |
| 문제 10점 | 선지 설계 | 선택지 비교 단위 통일 | 선택지 5개가 모두 사건, 정책, 제도, 인물, 단체 활동, 문화유산 등 같은 종류로 비교된다 |
| 문제 10점 | 선지 설계 | 오답 분류 유사성 | target_score 기준 개수 이상의 오답이 정답과 같은 주제·제도·사건·인물·단체 범주에 속한다 |
| 문제 10점 | 선지 설계 | 오답 시대 유사성 | target_score 기준 개수 이상의 오답이 정답과 같은 시대 또는 인접 시대에 속한다 |
| 문제 10점 | 선지 설계 | 선택지 중복 없음 | 선택지끼리 같은 내용 반복, 포함 관계, 사실상 같은 의미가 없다 |
| 문제 10점 | 선지 설계 | 정답 단서 비노출 | 정답 선지만 길이, 발문 단어 반복, 고유명사 수, 구체성에서 눈에 띄지 않는다 |
| 해설 5점 | 해설 품질 | 정답 근거 제시 | 해설에 정답 선지가 정답인 이유가 1개 이상 제시되어 있다 |
| 해설 5점 | 해설 품질 | 단서 사용 설명 | 해설이 자료 또는 발문의 어떤 단서를 사용해 정답을 도출했는지 설명한다 |
| 해설 5점 | 해설 품질 | 오답 배제 설명 | 해설이 오답 중 최소 2개에 대해 발문 조건에서 제외되는 이유를 설명한다 |
| 해설 5점 | 해설 품질 | 정답-해설 일치 | 해설의 정답 번호와 핵심 설명이 표시 정답과 일치한다 |
| 해설 5점 | 해설 품질 | 해설 사실성 | 해설에 명백한 역사 오류나 문항과 무관한 설명이 없다 |

## 11. target_score 기준표

| 기준 | 1점 | 2점 | 3점 |
|---|---|---|---|
| 단서 묶음 수 | 핵심 단서 1묶음으로 식별 가능 | 서로 다른 단서 2묶음 연결 | 3묶음 이상 또는 두 사건·자료 관계 판단 |
| 단서 간접성 | 정답 대상 명칭·대표 키워드 직접 제시 허용 | 직접 명칭 없이 대표 단서로 추론 | 우회 표현, 사료 문장, 간접 단서로 추론 |
| 풀이 단계 | 식별 후 바로 선택 | 식별 후 특징·활동·시기 비교 | 식별 후 순서·전후·인과·세부 차이 판단 |
| 지식 깊이 | 대표 개념 | 심화 표준 개념 | 세부 제도·사건·단체·인물 구분 |
| 유사 오답 수 | 0~1개 허용 | 최소 2개 | 최소 3개 |

## 12. 오답 유사성 적용 규칙

| 항목 | 적용 |
|---|---|
| 오답 분류 유사성 | target_score 기준의 유사 오답 수를 충족해야 함 |
| 오답 시대 유사성 | target_score 기준의 유사 오답 수를 충족해야 함 |
| 3점 문항 | 오답 최소 3개가 정답과 같은 대주제, 같은 전개 과정, 같은 시대권 중 하나에 속해야 함 |
| 부적합 예 | 정답만 특정 시기에 있고 오답 다수가 너무 먼 시대·무관한 주제라 쉽게 제거됨 |

## 13. 3점 난이도 보강 규칙

| 기준 | 3점 적합 |
|---|---|
| 단서 묶음 | 3묶음 이상 또는 두 사건·자료의 전후 관계 판단 |
| 풀이 단계 | 식별 후 순서·전후·인과·세부 차이 판단 |
| 오답 유사성 | 오답 최소 3개가 정답과 같은 대주제, 같은 전개 과정, 같은 시대권 중 하나에 속함 |
| 부적합 예 | 정답만 특정 시기에 있고 오답 다수가 너무 먼 시대·무관한 주제라 쉽게 제거됨 |

## 14. 최종 판정

| 결과 | 처리 |
|---|---|
| Gate FAIL | regenerate |
| Gate uncertain | needs_verification |
| Gate PASS, 14~15점 | accept |
| Gate PASS, 12~13점 | accept_with_warning |
| Gate PASS, 9~11점 | revise |
| Gate PASS, 8점 이하 | regenerate |
