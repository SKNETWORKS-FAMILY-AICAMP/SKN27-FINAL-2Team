HiMate — AWS 전체 구성도 ap-northeast-2 (서울)

초기 저비용 구성: ALB·NAT Gateway 미사용 · Elastic IP + 단일 Web EC2 · Aurora auto-pause · 배치 리소스는 주 1회만 기동 (deployment/ecs · fact-batch 기준)
비용 설계 요점: ALB·NAT 없이 Elastic IP + 단일 Web EC2 · Aurora 0 ACU auto-pause · GPU 추론은 상시 서버 대신 RunPod Serverless · Fact Neo4j·문제 생성은 EventBridge가 EC2를 켰다 끄는 주 1회 배치. Fact EC2는 NAT가 없으므로 Public Subnet에서 외부 API를 직접 호출. 정적 파일은 Django WhiteNoise가 서빙하며 Nginx는 HTTPS 종료·프록시·rate limit을 담당.
