# 공식 원천 중심 사실 관계 EDA

> 상태: `CURRENT`
> 기준일: 2026-07-26
> 실행: `run_source_first_fact_eda.py`
> LLM 호출: 없음
> Neo4j 적재: 없음

## 1. 결론

기출 선지에서 관계를 먼저 만들고 같은 표현을 공식 문서에서 찾는 방식은
엄격 승인 관계가 약 52건에 머무른다. 이는 전체 사실 그래프의 크기가 아니라
기출 문장과 공식 문장의 직접 일치 건수다.

공식 원천을 먼저 그래프로 만들고 기출 용어를 anchor로 대조하면 현재 데이터에서
다음 규모를 사용할 수 있다.

| 구분 | 건수 |
|---|---:|
| ACTIVE `CanonicalEntity` | 4,786 |
| 단일 승인 기출 anchor canonical | 2,921 |
| 기존 canonical 사실 | 1,234 |
| 기출 anchor를 하나 이상 포함한 기존 사실 | 1,176 |
| 기출 anchor끼리 연결된 기존 사실 | 755 |
| 분류 문맥 관계를 제외한 기존 사실 | 548 |
| 기출 anchor를 포함한 교체 탐색용 기존 사실 | 490 |
| 기출 anchor끼리 연결된 교체 탐색용 기존 사실 | 299 |
| 신규 자동 후보 | 30 |
| 기존 사실과 겹치지 않는 신규 자동 후보 | 24 |
| 신규 자동 후보 중 기출 anchor끼리 연결 | 16 |
| 예상 교체 탐색용 기출 anchor 간 사실 | **315** |

따라서 현재의 안전한 실사용 기준은 `52`가 아니라 우선 **315개 직접 사실**이다.
분류·시대 문맥까지 포함한 전체 기출 anchor 간 그래프 관계는 **771개**다.

기존 RAG 전처리에는 이 사실 그래프로 만든 교체 후보가 1,464행 존재한다. 이 값은
최종 오답 수가 아니라 truth gate 이전 탐색 후보 수다.

## 2. 접근 변경

### 이전 방식

1. 기출 정답 선지에서 관계 후보 생성
2. 기출 문장의 두 endpoint를 먼저 확정
3. 같은 endpoint와 같은 서술어가 있는 공식 문장 검색

endpoint 생략, 동의 서술어, 문장 구조 차이 때문에 공식 데이터가 많아도 관계가
거의 늘지 않았다.

### 현재 EDA 방식

1. ITKC·AKS·용어집을 공식 사실의 시작점으로 사용
2. 공식 원천에서 canonical endpoint와 역할을 먼저 확정
3. 만들어진 사실 중 기출 용어 canonical과 연결되는 사실을 선택
4. RAG가 같은 관계와 경로를 공유하는 다른 대상을 탐색

기출은 사실을 생성하는 유일한 원천이 아니라 그래프 탐색 anchor로 사용한다.

## 3. 안전 등급

### 기존 canonical 사실

현재 1,234건이며 원천별 포함 건수는 다음과 같다. 한 사실에 여러 원천이 있을 수
있으므로 합계는 1,234보다 클 수 있다.

| 원천 | 사실 포함 건수 |
|---|---:|
| AKS 설명 패턴 | 564 |
| ITKC 인물 구조 관계 | 331 |
| ITKC 사건–인물 구조 관계 | 23 |
| 용어집 설명 패턴 | 447 |

### 신규 자동 후보

AKS 문장에 다음 조건을 모두 만족할 때만 자동 후보로 둔다.

- 두 endpoint 모두 canonical로 해소되는 EID 링크
- 같은 원자 절 안에서 두 링크만 행동 인자로 등장
- 두 endpoint 모두 술어 앞에 위치
- 조사와 태로 역할쌍을 하나만 결정 가능
- 관계 계열별 역할·EntityType 계약 일치
- 부정, 불확실성, 미실행 계획, 중간 행동 건너뛰기 없음

전체 75,835개 AKS 문서와 1,780,915개 문장을 검사한 결과:

| 결과 | 건수 |
|---|---:|
| 직접 EID 역할 근거 | 68 |
| 자동 후보 사실 | 30 |
| 신규 자동 후보 사실 | 24 |

30건은 전수 문장 확인을 수행했다. 이 EDA에서는 후보로만 저장했으며 적재하지 않았다.

### 검토 후보

다음은 자동 승인하지 않는다.

- 역할·EntityType 계약을 통과하지 못한 AKS 직접 EID 관계
- 용어집 표제어와 본문의 고유 canonical 이름으로 추론한 관계

| 구분 | 후보 사실 |
|---|---:|
| 전체 검토 후보 | 138 |
| 용어집 표제어 역할 근거 | 114개 evidence |

용어집은 EID 링크가 없으므로 공식 문서라는 이유만으로 자동 승인하지 않는다.

## 4. 교체 탐색 가능성

`ASSOCIATED_WITH_POLITY`처럼 분류·시대 탐색에 쓰는 문맥 관계를 제외하면 기출
anchor끼리 연결된 기존 사실은 299개다.

| 교체 방향 | 분기 그룹 | 해당 사실 |
|---|---:|---:|
| 같은 시작점·관계에서 마지막 대상 교체 | 31 | 76 |
| 같은 대상·관계에서 시작 인물·기관 교체 | 35 | 106 |

이는 1-hop 직접 교체만 센 값이다. 실제 RAG는 최대 4-hop을 사용할 수 있어
현재 `rag_swap_candidates.csv`에는 1,464개 후보가 있다.
