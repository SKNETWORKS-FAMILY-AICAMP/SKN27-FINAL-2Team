# 한국사 기출 정답–오답 관계 분석

입력은 일반 5지선다 기출문항 한 개이다. 원문을 고치지 말고, 정답 선지와
각 오답 선지의 의미 차이를 검색 가능한 구조로 분석한다.

## 분석 원칙

1. `is_answer_key`는 시험 정답 표시이고 역사 명제의 독립적인 사실성과 구분한다.
2. `question_target`에는 자료와 발문이 가리키는 실제 시대·국가·인물·사건·제도 등을 적는다.
3. 각 선지의 `contextual_validity`는 그 선지를 발문의 대상과 조건에 적용했을 때의 적합성을 뜻한다.
4. `standalone_fact_status`는 선지가 다른 실제 대상·시대의 사실로 성립하는지도 고려한다.
5. 정상 오답이 다른 대상의 실제 사실이라면 `actual_fact`에 그 대상과 사실을 적는다.
6. 확인할 수 없는 세부 내용은 추측하지 말고 빈 문자열과 `UNCERTAIN`을 사용한다.
7. 정답 선지를 포함한 모든 선지를 정확히 한 번씩 `choice_claims`에 기록한다.
8. 각 오답은 정답 선지와 정확히 한 번 비교하여 `distractor_relations`에 기록한다.
9. 가장 직접적인 차이는 `primary_relation_type`, 함께 작동하는 차이는
   `secondary_relation_types`에 중복 없이 기록한다.
10. 관계는 차이를 설명하는 데 필요한 최소 개수만 기록한다. 주 관계에 이미 포함된
    일반적인 속성 차이를 보조 관계로 반복하지 않는다.
11. `TARGET_SWAP`이 주 관계이면 대상이 달라져 활동도 달라졌다는 이유만으로
    `ATTRIBUTE_SWAP`을 추가하지 않는다.
12. `TIME_SHIFT`가 주 관계이면 시대가 달라져 생활·정책도 달라졌다는 이유만으로
    `ATTRIBUTE_SWAP`을 추가하지 않는다.
13. `ATTRIBUTE_SWAP`은 대상과 시대가 유지되는데 활동·정책·제도·유물 등의 속성만
    바뀐 경우에 사용한다.
14. `CAUSE_RESULT_CONFUSION`은 같은 사건의 원인·과정·결과를 직접 뒤바꾼 경우에
    사용한다. 결과를 묻는 발문에 별개의 이전 시기 정책을 제시했다면
    `TIME_SHIFT`를 주 관계, `CATEGORY_MISMATCH`를 보조 관계로 사용한다.
15. `shared_dimensions`와 `changed_dimensions`에는 허용된 값만 중복 없이 기록한다.
16. 원문 선지의 단순 문자열 유사도가 아니라 역사적 대상·시대·속성의 차이를 판단한다.
17. 원본 이미지·표·지도·도판이 없어도 문항을 제외하지 말고, 자료 설명·발문·정답
    표시·선지를 이용해 모든 관계를 분석한다. 실제로 확정할 수 없는 필드만
    빈 문자열 또는 `UNCERTAIN`으로 기록한다.

## 관계 우선순위

- 다른 인물·국가·사건·제도의 완성된 실제 사실을 적용했으면
  `TARGET_SWAP`을 주 관계로 사용한다.
- 같은 대상을 유지하면서 시대 조건만 달라졌으면 `TIME_SHIFT`를 주 관계로 사용한다.
- 대상과 시대가 모두 다르면 `TARGET_SWAP`을 주 관계,
  `TIME_SHIFT`를 보조 관계로 사용한다.
- 발문 핵심이 장소이고 실제 장소를 바꿨으면 `LOCATION_SWAP`을 주 관계로 사용한다.
- 대상과 시대가 유지된 채 활동·정책·속성만 바뀌었으면
  `ATTRIBUTE_SWAP`을 사용한다.
- 서로 맞지 않는 요소를 결합해 실제 사실이 성립하지 않으면
  `FALSE_COMBINATION`을 사용한다.
- 원인과 결과를 직접 뒤바꿨으면 `CAUSE_RESULT_CONFUSION`을 사용한다.

## 주요 오답 관계

- `TARGET_SWAP`: 같은 종류의 사실을 다른 국가·인물·제도에 바꾸어 적용
- `TIME_SHIFT`: 정답 조건보다 앞이나 뒤 시대의 사실로 교체
- `ATTRIBUTE_SWAP`: 활동·정책·사건·유물 등의 속성을 교체
- `CAUSE_RESULT_CONFUSION`: 사건의 원인·결과·영향을 혼동
- `LOCATION_SWAP`: 실제 지역이나 지도상의 위치를 교체
- `CATEGORY_MISMATCH`: 발문이 요구한 응답 범주와 다른 범주의 선지
- `FALSE_COMBINATION`: 실제 역사에서 성립하지 않는 요소 결합
- `OTHER`: 위 유형으로 설명하기 어려운 경우

출력은 지정된 JSON Schema를 만족하는 JSON 객체 하나만 반환한다.
