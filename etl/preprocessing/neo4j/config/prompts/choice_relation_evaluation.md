# 한국사 정답–오답 관계 독립 평가

입력에는 원문 문항과 별도 생성 모델의 관계 분석 제안이 함께 제공된다.
제안의 결론과 confidence를 신뢰하지 말고 원문을 기준으로 독립적으로 검증한다.

## 평가 범위

1. OCR·입력 품질은 `source_task`의 기출문제 원문인 `material`, `question`,
   `choices[].text`에만 판정한다. 생성 제안, 검색 결과, API로 가져온 공식 문서의
   표기나 HTML 추출 상태를 기출문제 OCR 문제로 판정하지 않는다.
2. `question_target`의 인물·국가·사건·제도·시대가 맞는지 확인한다.
3. 모든 선지의 맥락상 적합성과 `actual_fact`의 실제 주체·시대·내용을 확인한다.
4. 모든 정답–오답 관계의 주 관계와 보조 관계가 실제 의미 차이를 나타내는지 확인한다.
5. 확인할 수 없는 사실을 추측하여 `SUPPORTED`로 판정하지 않는다.
6. 오류를 발견하면 자동으로 승인하지 말고 `CONTRADICTED` 또는 `UNVERIFIABLE`로 판정한다.
7. 내부 기억만으로 확정하지 말고 웹 검색으로 핵심 사실을 교차 확인한다.
8. 검색 결과가 부족하거나 신뢰할 만한 근거가 없으면 `UNVERIFIABLE`로 판정한다.

## 입력 품질 판정

- 조사·띄어쓰기·문장 부호·명백한 한두 글자 오타처럼 의미와 정답 판별에
  영향을 주지 않는 오류는 `CLEAN`으로 판정한다. 필요하면
  `input_quality_issues`에 참고 사항만 기록한다.
- 핵심 인물·연도·부정 표현·사건명이 손상되어 의미를 신뢰성 있게 복원할 수
  있을 때만 `OCR_SUSPECTED`로 판정한다.
- 원본 이미지·표·지도·도판이 제공되지 않았으면 `MISSING_CONTEXT`로 표시하되,
  그것만으로 대상·주장·관계를 `UNVERIFIABLE`로 낮추지 않는다.
- 이미지·표가 없어도 자료 설명, 발문, 정답 표시, 선지 및 공식 근거를 이용해
  모든 대상·주장·관계를 끝까지 평가한다.
- 누락된 시각 자료 때문에 특정 판단을 실제로 확정할 수 없는 항목만
  `UNVERIFIABLE`로 판정하며 문항 자체를 제외하지 않는다.

## 관계 우선순위

- 다른 인물·국가·사건·제도의 실제 사실을 적용했으면 `TARGET_SWAP`을 주 관계로 사용한다.
- 같은 대상을 유지하면서 시대 조건만 달라졌으면 `TIME_SHIFT`를 주 관계로 사용한다.
- 발문 핵심이 장소이고 실제 장소를 바꿨으면 `LOCATION_SWAP`을 주 관계로 사용한다.
- 대상과 시대가 유지된 채 활동·정책·속성만 바뀌었으면 `ATTRIBUTE_SWAP`을 사용한다.
- 서로 맞지 않는 요소를 결합해 실제 사실이 성립하지 않으면 `FALSE_COMBINATION`을 사용한다.
- 원인과 결과를 직접 뒤바꿨으면 `CAUSE_RESULT_CONFUSION`을 사용한다.
- 대상과 시대가 모두 다르면 다른 실제 대상의 완성된 사실을 가져왔는지 먼저 판단한다.
  그렇다면 `TARGET_SWAP`을 주 관계, `TIME_SHIFT`를 보조 관계로 사용한다.

`corrected_actual_fact`와 교정 관계 필드는 평가 근거를 기록하기 위한 제안이다.
생성 결과가 맞으면 기존 `actual_fact`를 표현까지 그대로 복사하고, 틀렸을 때만
올바른 사실로 교정한다. 단순한 문장 다듬기나 동의어 교체는 하지 않는다.

관계 제안이 틀렸지만 올바른 관계를 근거로 확정할 수 있으면 `CONTRADICTED`로
판정하고 `corrected_primary_relation_type`과
`corrected_secondary_relation_types`에 확정한 관계를 기록한다. 관계를
확정할 수 없을 때만 `UNVERIFIABLE`로 판정한다.

출력은 지정된 JSON Schema를 만족하는 JSON 객체 하나만 반환한다.
